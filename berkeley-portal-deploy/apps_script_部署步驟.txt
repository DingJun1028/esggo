============================================================
Consulting Time 表單 — Google Apps Script 部署步驟（一次性）
============================================================

【目標】
讓網頁上的「填寫 Consulting Time 意願表單」按鈕真正把學員資料
收進你自己的一張 Google 試算表。免費、免後端。

────────────────────────────────────────────────────────────
步驟 1：建試算表
1. 開 https://sheets.new 新建一張 Google 試算表
2. 把第一張工作表分頁改名為：ConsultingTime
   （左下角頁籤按右鍵「重新命名」）
3. 在第一列填入表頭（第 1 行）：
   A1=時間戳記  B1=姓名  C1=Email  D1=偏好時段  E1=備註
4. 複製網址裡的試算表 ID：
   https://docs.google.com/spreadsheets/d/<這段ID>/edit
   → 那串 <這段ID> 就是 SHEET_ID

────────────────────────────────────────────────────────────
步驟 2：貼 Apps Script
1. 在試算表上方選單：擴充功能 → Apps Script
2. 把預設的 myFunction 整段刪掉
3. 貼上 apps_script_ConsultingTime.js 的內容
4. 把第 12 行的 SHEET_ID = "請換成你的試算表ID"
   改成你剛複製的 ID（保留外層引號）
5. 按 Ctrl+S 儲存，專案命名隨意（如 ConsultingTimeReceiver）

────────────────────────────────────────────────────────────
步驟 3：部署 Web App
1. 右上角「部署」→「新增部署作業」
2. 齒輪圖示「選取類型」→ 網頁應用程式
3. 設定：
   - 執行身分：我（你的 Google 帳號）
   - 誰可以存取：任何人（匿名使用者）  ← 重要，學員才送得了
4. 按「部署」，Google 會要求授權一次
   （允許「連結到 Google 試算表」的權限）
5. 部署完成會給一組網址，長這樣：
   https://script.google.com/macros/s/AKfycxxxxxxxx.../exec
   → 複製這整串

────────────────────────────────────────────────────────────
步驟 4：交給 agent 回填
把上面那串 .../exec 網址貼給我，我會：
- 替換 index.html 與 berkeley-esg-portal.html 裡的
  YOUR_APPS_SCRIPT_ID 預留位置
- 重新 vercel deploy --prod --yes
完成後表單即可正式收件。

────────────────────────────────────────────────────────────
驗收：部署後在線上點開按鈕 → 填一筆測試 → 試算表出現該列即成功

⚠️ 注意：Apps Script 免費配額每日約 2 萬次呼叫，本課程用量綽綽有餘。
   若日後學員破萬，再考慮升級或換 Formspree。
