# 萬能元件 OmniComponents

[Ω-C | 萬能能力維度 · 元件層]

> **所屬體系：** 萬能系統（Omni System）  
> **上層目錄：** [萬能目錄](../萬能目錄.md)  
> **生產者：** [萬能工廠](./萬能工廠.md)  
> **定義：** 萬能元件是基於 [萬能函數](./萬能函數.md) 與 [萬能主題](./萬能主題.md) 構成、可拖拽組合的視覺與交互單元，依原子設計（Atomic Design）分為原子 / 分子 / 生物三級。

---

## 1. 元件分類總覽（MECE 進化版 · Ω-C 軸）

| 層級           | 代碼     | 說明                   | 實作來源                         |
| -------------- | -------- | ---------------------- | -------------------------------- |
| 原子 Atoms     | `C-ATOM` | 不可再分的最小 UI 單元 | `品牌原子元件庫.md`              |
| 分子 Molecules | `C-MOL`  | 2+ 原子組合的功能單元  | `品牌原子元件庫.md`              |
| 生物 Organisms | `C-ORG`  | 完整區塊 / 頁面框架    | `packages/ui/src/solid-card.tsx` |

---

## 2. 原子級元件 `C-ATOM`

| 元件             | 用途                   | 驅動函數          | 使用模組             |
| ---------------- | ---------------------- | ----------------- | -------------------- |
| `BrandStatusDot` | 顯示 5T 狀態（T1–T5）  | `getGateColor`    | 全部含狀態頁         |
| `BrandBadge`     | GRI / ISO 標準標籤     | `createOmniTag`   | 重大性矩陣、專家模板 |
| `BrandButton`    | 含 5T 封印動畫的操作鈕 | —                 | 全部操作頁           |
| `BrandAvatar`    | SPIRIT 人格 / 代理身份 | `createOmniAgent` | 專家諮詢、代理專區   |

對應 Solid Card 原語：`Badge`（variant: teal/gold/blue/success/warning/error/muted）、`Button`（variant: primary/secondary/ghost/danger）。

---

## 3. 分子級元件 `C-MOL`

| 元件             | 用途                     | 驅動函數                        | 使用模組                             |
| ---------------- | ------------------------ | ------------------------------- | ------------------------------------ |
| `BrandKpiCard`   | KPI 卡（公式＋來源＋5T） | `aggregateKpi` + `getGateColor` | 控制台、環境指揮、社會影響、公司治理 |
| `BrandT5Strip`   | 單筆資料 5T 完整度條     | `validate*` 系列                | 證據金庫、SustainWrite               |
| `BrandSearchBar` | GRI 自動補全搜尋         | `pairTags`                      | 全域導覽、永續智庫                   |

對應 Solid Card 原語：`MetricCard`（label/value/unit/change/trend/icon）、`Card`（variant: default/highlight/success/warning/error）、`CardHeader`、`Section`。

---

## 4. 生物級元件 `C-ORG`

| 元件                  | 用途                                  | 驅動函數                              | 使用模組           |
| --------------------- | ------------------------------------- | ------------------------------------- | ------------------ |
| `VaultOmniTable`      | 萬能聖碑表（即時 SHA-256 + ZKP 標識） | `sealContent` / `verifySeal`          | 證據金庫、審計日誌 |
| `HermesFloatingAgent` | 全域懸浮 AI 助手（語音＋視覺掃描）    | `createOmniAgent` / `executeAssembly` | 所有頁面           |
| `StandardPage`        | 12 欄 Bento Grid 頁面框架             | `getDesignTokens`                     | 全部頁面基底       |

---

## 5. 元件組裝約定（工廠契約）

1. 元件不可直接寫死色值，一律取用 [萬能主題](./萬能主題.md) 的 CSS 變數（`--accent-teal` 等）。
2. 任何含資料的元件必須接收經 [萬能函數](./萬能函數.md) `F-5T` 閘門後的資料。
3. 生物級元件的佈局必須符合 `StandardPage` 的 12 欄 Bento Grid 柵格。
