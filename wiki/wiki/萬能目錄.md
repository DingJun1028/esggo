# 萬能目錄 OmniCatalog

> **定義：** 萬能系統（Omni System）的頂層目錄，統治所有 [萬能工廠](./萬能工廠.md) 的分類法、[萬能函數](./萬能函數.md) 的 MECE 進化版、[萬能元件](./萬能元件.md) 的原子設計層級、[萬能主題](./萬能主題.md) 的設計 Token、[萬能符文](./萬能符文.md) 的語意標記。
>
> **核心協定：** 5T 誠信協議（真／善／美／信／通）＋終始矩陣（以終為始）

## 1. MECE 進化版（Evolved MECE）雙軸分類法

### 軸 1：MEDCE 治理軸（水平—生命週期階段）

| 字母 | 全義 | 治理階段 | 核心問題 |
| ---- | ---- | -------- | -------- |
| **M** | Measurement 測量 | 量化現狀 | 我們現在在哪？ |
| **E** | Evaluation 評估 | 缺口分析 | 我們離目標多遠？ |
| **D** | Disclosure 揭露 | 對外出示 | 我們如何對外界說明？ |
| **C** | Compliance 合規 | 確信稽控 | 我們是否符合規範？ |
| **A** | Engagement 參與 | 利害關係經營 | 誰參與、如何共創？ |

> 進化版將原第二個 E（參與）重新編碼為 A，解決字母碰撞，達成真正 MECE。

### 軸 2：OMNI 能力軸（垂直—萬能工廠四族）

| 字母 | 全義 | 原料層 | 代碼 |
| ---- | ---- | ------ | ---- |
| **Ω-F** | Functions | 萬能函數 | `F-*` |
| **Ω-C** | Components | 萬能元件 | `C-*` |
| **Ω-T** | Themes | 萬能主題 | `T-*` |
| **Ω-R** | Runes | 萬能符文 | `R-*` |
| **Ω-A** | Assembly | 萬能工廠組裝層 | `assemble.mjs` |

## 3. 終始矩陣（Terminal-Origin Matrix）

> **原則：** 以終為始 — 從最終成品（萬能模組）的規格倒推，確保每一行代碼都對應一個已註冊的需求。

```
 需求 (README)          過程 (Factory)           成果 (Module)
 ─────────────         ─────────────            ─────────────
 功能定位      ──►    P1 需求解析      ──►    MOD-XXX
 路徑/權限     ──►    P2 函數選配      ──►    函數組合
 資料視覺化    ──►    P3 元件拼裝      ──►    元件樹
 品牌一致性    ──►    P4 主題套用      ──►    視覺實例
 5T 合規      ──►    P5 符文標記      ──►    帶語義成品
 品質驗證      ──►    P6 5T 閘門      ──►    通過/退件
 封印註冊      ──►    P7 代理封印      ──►    hashLock + 註冊表
```

**對映關係：**
- 每個 README 章節 → 一個 ModuleSpec 欄位
- 每個 ModuleSpec 欄位 → 一個 Factory 階段
- 每個 Factory 階段 → 一個可執行產出
- 每個產出 → 一個 5T 閘門驗證
