# 萬能函數 OmniFunctions

[Ω-F | 萬能能力維度 · 函數層]

> **所屬體系：** 萬能系統（Omni System）  
> **上層目錄：** [萬能目錄](../萬能目錄.md)  
> **生產者：** [萬能工廠](./萬能工廠.md)  
> **定義：** 萬能函數是平台內「純邏輯、可復用、無副作用依賴 UI」的最小能力單元。任何 [萬能模組](./萬能模組-註冊表.md) 的行為皆由一組萬能函數組裝而成。

## 2. 代理核心函數 `F-AGENT`

### `createOmniAgent(name, mode)` — 創建萬能代理

- **簽章：** `createOmniAgent(name?: string, mode?: 'autonomous'|'supervised'|'debug') => OmniAgent`
- **來源：** `lib/omni-agent/index.ts`
- **行為：** 生成具 `id / agentHash / capabilities / trinitySyncEnabled` 的不可變代理實體。
- **使用模組：** 控制台、代理專區、AI 整合平台、數位分身。

### `executeAssembly(agent, task)` — 執行報告組裝

- **簽章：** `executeAssembly(agent: OmniAgent, task: AssemblyTask) => AssemblyResult`
- **行為：** 為每個章節創建萬能標籤 → 量子配對 → 5T 閘門驗證 → 計算 Trinity Hash → 產出 `hashLock`。
- **使用模組：** SustainWrite、報告發佈、永續智庫。

### `recordDecision(agent, gate, action, input, output)` — 記錄決策

- **行為：** 將代理的每一次決策以 `hashLock` 固化，可追溯（5T-T3 美）。
- **使用模組：** 審計日誌、證據金庫、企業健檢。

### `getAgentStatus(agent)` / `createDefaultTask(companyId, companyName)`

- 狀態報表與預設 28 章節任務模板（v5-ch01…v5-ch28）。

---

## 3. 標籤同步函數 `F-TAG`

### `createOmniTag(chapter, standard, anchor)` — 創建萬能標籤

- **來源：** `lib/omni-tag/index.ts`
- **行為：** 將章節/指標繫結至標準（GRI/ISSB/TCFD）與證據錨點，產生可糾纏標籤。
- **使用模組：** 重大性矩陣、專家模板、證據金庫。

### `pairTags(tagA, tagB)` — 量子配對

- **行為：** 建立雙向同步配對，任一端變動即觸發對端更新（萬能標籤核心機制）。

---

## 4. 主題適配函數 `F-THEME`

### `getGateColor(gate)` — 取得 5T 閘門色

- **簽章：** `getGateColor(gate: FiveTGate) => { bg, text, accent, label }`
- **來源：** `lib/omni-theme/design-system.ts`
- **使用模組：** 所有含 5T 狀態條的頁面。

### `getDesignTokens()` — 取得設計 Token

- 回傳 `DESIGN_TOKENS`（teal / gold / zkpBlue / 字級），供 [萬能元件](./萬能元件.md) 與 [萬能主題](./萬能主題.md) 取用。

---

## 5. 誠信閘門函數 `F-5T`

| 函數               | 閘門  | 驗證方式                 |
| ------------------ | ----- | ------------------------ |
| `validateTruth`    | T1 真 | 數值 / 單位 / 時間戳齊備 |
| `validateGoodness` | T2 善 | 來源標記存在             |
| `validateBeauty`   | T3 美 | 稽核軌跡存在             |
| `validateTrust`    | T4 信 | `hash_lock` 不可篡改     |
| `validateTransfer` | T5 通 | 第三方可驗算             |

- **來源：** `src/lib/five-t-protocol.ts`、`src/lib/omni-core/omni-kernel.ts`
- **使用模組：** 證據金庫、VerifyLink™、審計日誌、SustainWrite。

---

## 6. 證據封印函數 `F-SEAL`

### `sealContent(content, meta)` — 內容封印

- **來源：** `lib/omni-agent` / `cli.vault.seal`
- **行為：** SHA-256 + ZKP 封印，回傳可驗證憑證。
- **使用模組：** 證據金庫、VerifyLink™、專家模板。

### `verifySeal(credential)` — 驗證封印

- **使用模組：** VerifyLink™、永續閱覽室。

## 8. 函數調用約定（工廠契約）

1. 所有函數必須為 **純函數** 或返回 **不可變（frozen）物件**。
2. 任何產出資料必須經 `F-5T` 閘門後方可進入 [萬能元件](./萬能元件.md)。
3. 需要跨頁複用的函數須註冊於本目錄，禁止頁面內私有重複實作。
