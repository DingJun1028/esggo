# 治理面板

**功能分類**：E 評估 / G 管理  
**路徑**：`/dashboard`  
**描述**：ESG 治理核心指揮中心，整合 5T 協議執行狀態監控

## 5T 特性

- **Tangible**：即時圖表顯示治理指標KPI
- **Traceable**：點擊每個指標可查看數據來源與計算步驟
- **Trackable**：面板操作自動寫入治理Audit Log
- **Transparent**：開放所有治理指標的計算公式與驗證方法
- **Trustworthy**：關鍵治理決策Hash鎖存證

## 核心模組

| 模組 | 功能 | API |
|------|------|-----|
| KPI概覽 | 顯示核心ESG指標 | `GET /api/kpis/summary` |
| 風險儀表板 | 風險等級分級 | `GET /api/risk/levels` |
| 合規檢查 | 5T 合規度檢查 | `GET /api/compliance/status` |
| 行動建議 | AI 施策建議 | `POST /api/recommendations` |

## 觸發指令

- 刷新狀態：`Ctrl+R`
- 檢視證據：點擊任一指標的「Trace」圖示
- 匯出報表：點擊「Export」按鈕
