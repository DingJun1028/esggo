# 首頁

**功能分類**：M 測量 / E 評估  
**路徑**：`/`  
**描述**：系統入口，整合 ESG 治理概覽與核心指揮中心

## 5T 特性

- **Tangible**：即時顯示 ESG KPIs 數值標籤
- **Traceable**：點擊指標溯源至原始數據收集
- **Trackable**：操作流程自動記錄於Audit Log
- **Transparent**：開放治理指標計算公式
- **Trustworthy**：關鍵指標Hash鎖存證

## 核心組件

| 組件 | 功能 |
|------|------|
| OmniKpiCard | KPI儀表卡片 |
| GovernanceDashboard | 治理概覽面板 |
| QuickActions | 快速操作列 |

## API 端點

- `GET /api/kpis` - 取得核心KPI指標
- `GET /api/governance/summary` - 治理摘要概況
