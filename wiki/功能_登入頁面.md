# 登入頁面

**功能分類**：C 合規 / M 測量  
**路徑**：`/login`  
**描述**：系統存取入口，支援單點登入（SSO）與多因素驗證

## 5T 特性

- **Tangible**：視覺化顯示驗證狀態與會話時間
- **Traceable**：登入紀錄自動寫入事件Log
- **Trackable**：Session ID 可追蹤整個操作痕跡
- **Transparent**：錯誤訊息明確說明失敗原因
- **Trustworthy**：密碼輸入於前端加密後傳送

## 身份驗證流程

1. 輸入帳號密碼
2. 雙因素驗證（如啟用）
3. JWT Token 簽發
4. 跳轉至登錄成功頁

## API 端點

- `POST /api/auth/login` - 登入驗證
- `POST /api/auth/2fa` - 雙因素驗證
- `GET /api/auth/session` - 取得當前Session
