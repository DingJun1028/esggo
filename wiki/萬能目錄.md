## 1. MECE 進化版（Evolved MECE）雙軸分類法

原 MEDCE 以 `M/E/D/C/E` 五維描述治理生命週期，但 **評估(E) 與 參與(E)** 字母碰撞，並未真正互斥。  
**進化版** 將之分為正交的兩軸，達成嚴格 MECE：

### 軸一 · 治理生命週期軸（MEDCE，重新編碼）

| 代碼  | 中文 | 英文        | 核心定義                             |
| ----- | ---- | ----------- | ------------------------------------ |
| **M** | 測量 | Measurement | 數據採集、指標定義、KPI 監測         |
| **E** | 評估 | Evaluation  | 重大性、風險、成熟度評析             |
| **D** | 揭露 | Disclosure  | 報告撰寫、對外發佈、透明度           |
| **C** | 合規 | Compliance  | 法規遵循、審計、驗證封印             |
| **A** | 參與 | Engagement  | 利害關係人、顧問、AI 協作（原 E②→A） |

### 軸二 · 萬能能力維度軸（OMNI，Ω 五層）

| 代碼    | 名稱             | 目錄入口                       |
| ------- | ---------------- | ------------------------------ |
| **Ω-F** | 萬能函數         | [萬能函數](./wiki/萬能函數.md) |
| **Ω-C** | 萬能元件         | [萬能元件](./wiki/萬能元件.md) |
| **Ω-T** | 萬能主題         | [萬能主題](./wiki/萬能主題.md) |
| **Ω-R** | 萬能符文         | [萬能符文](./wiki/萬能符文.md) |
| **Ω-A** | 萬能代理（工廠） | [萬能工廠](./wiki/萬能工廠.md) |

> 任一 [萬能模組](./wiki/萬能模組-註冊表.md) 皆以 `(主 MEDCE 階段, Ω-組合)` 唯一標定，既互斥又窮盡。

## 4. 如何開始建置（依需求順序）

1. **先列目錄（本文件）** — 確認功能歸屬的 MEDCE 主階段與 Ω 組合。
2. 選配原料 — 自 [萬能函數](./wiki/萬能函數.md) / [萬能元件](./wiki/萬能元件.md) / [萬能主題](./wiki/萬能主題.md) / [萬能符文](./wiki/萬能符文.md) 取料。
3. 交給 [萬能工廠](./wiki/萬能工廠.md) — 走 P1–P7 流水線與 5T 閘門。
4. 產出並登錄 — 寫入 [萬能模組註冊表](./wiki/萬能模組-註冊表.md)，沉澱新原料回饋本目錄。
