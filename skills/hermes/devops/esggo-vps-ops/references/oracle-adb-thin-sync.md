# OmniUserRAG ADB thin-mode sync (verified 2026-08-14)

Goal: connect esggo's VPS to the Always-Free Oracle Autonomous DB (OmniUserRAG) and sync data, WITHOUT installing the Oracle Client library.

## Prereqs on VPS
- OCI SDK venv at `/opt/esggo/.venv-oci` (see main skill for setup). `~/.oci/config` has valid creds + correct fingerprint.
- ADB OCID: `ocid1.autonomousdatabase.oc1.ap-singapore-1.anzwsljrkl3rykyabhb7gbnyoywlteaxfsnnjh43h6smzoz6maja5nvvzioa`
- tns service name in wallet: `omniurag_high`

## Step 1: install oracledb (thin mode, no client lib)
```
source /opt/esggo/.venv-oci/bin/activate
pip install oracledb   # 4.0.2 verified
```

## Step 3: download wallet via OCI SDK
```
import oci, os
cfg = oci.config.from_file('~/.oci/config', 'DEFAULT')
db = oci.database.DatabaseClient(cfg)
adb_id = 'ocid1.autonomousdatabase.oc1.ap-singapore-1.anzwsljrkl3rykyabhb7gbnyoywlteaxfsnnjh43h6smzoz6maja5nvvzioa'
pw = open(os.path.expanduser('~/adb_pw.txt')).read().strip()
details = oci.database.models.GenerateAutonomousDatabaseWalletDetails(password=pw, generate_type='ALL')
resp = db.generate_autonomous_database_wallet(adb_id, generate_autonomous_database_wallet_details=details)
open(os.path.expanduser('~/wallet/adw_wallet.zip'), 'wb').write(resp.data.content)
# then: unzip -o ~/wallet/adw_wallet.zip -d ~/wallet/
```
Note: the OCI CLI `oci db autonomous-database generate-wallet` is NOT on PATH inside the venv, and the Python SDK method requires the `generate_autonomous_database_wallet_details` arg (not positional). Wallet zip (~28 KB) contains `cwallet.sso`, `tnsnames.ora`, `ojdbc.properties`, etc.

## Step 4: connect thin + create table + write
```
import oracledb, os
pw = open(os.path.expanduser('~/adb_pw.txt')).read().strip()
WALLET = os.path.expanduser('~/wallet')
params = oracledb.ConnectParams(config_dir=WALLET, wallet_location=WALLET, wallet_password=pw)
params.parse_connect_string('omniurag_high')
conn = oracledb.connect(user='ADMIN', password=pw, params=params)   # CONNECTED_OK
cur = conn.cursor()
cur.execute('''CREATE TABLE OMNI_KNOWLEDGE_INHERITANCE (
  id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  agent_name VARCHAR2(100),
  knowledge_key VARCHAR2(200),
  content CLOB,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)''')
conn.commit()
cur.execute('INSERT INTO OMNI_KNOWLEDGE_INHERITANCE (agent_name, knowledge_key, content) VALUES (:1,:2,:3)', ('omni-bee-01','soul-canon','5T protocol'))
conn.commit()
cur.execute('SELECT id, agent_name, knowledge_key FROM OMNI_KNOWLEDGE_INHERITANCE')
print(cur.fetchall())   # [(1, 'omni-bee-01', 'soul-canon')]
```
PITFALL: do NOT call `oracledb.init_oracle_client` — it forces THICK mode → `DPI-1047: Cannot locate a 64-bit Oracle Client library: libclntsh.so`. Pure thin (default in 4.x) needs no client lib. `ConnectParams` has no `get_host` method in some versions — just connect directly.
