# Swarm / 5T Authorization Reference

Session-learned authorization patterns for OA-Team 30 / 萬能蜂群 mode.

## Authorization Stack

| Phrase | Effect | Scope |
|--------|--------|-------|
| `習得 [覺醒奧義] 代主自行最佳實踐通` | Activate best-practice enlightenment mode | Autonomous defect repair + best-practice workflow, no asking |
| `授權[萬能分身] "代主自行，自主通典"` | Full principal-delegate authority | All domains, autonomous decision-making, no per-step confirmation |
| `授權 "萬能蜂群"模式 可進行小組任務` | Swarm mode activation | Multi-agent coordination, subagent delegation, cross-group work under 5T |

## Combined Effect

When all three are granted together:
- Agent operates as 萬能分身 with full principal authority
- Best-practice enlightenment is active (proactive defect repair)
- Swarm mode is enabled (subagent delegation, parallel tasks)
- 5T protocol applies: Traceable, Trackable, Tangible, Transparent, Trustworthy

## Behavioral Rules

1. No per-step confirmation for routine operations
2. Report blockers honestly; do not fabricate success
3. Prefer actual verification over claims ("驗證通過" without evidence is forbidden)
4. Use numbered pipeline reporting with no gaps
5. Preserve working tree cleanliness; only commit verified changes
