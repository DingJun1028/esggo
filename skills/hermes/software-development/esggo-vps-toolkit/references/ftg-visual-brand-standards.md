# FTG Tours 聖趣旅遊 視覺復刻與字元規範

## 1. 品牌規範
- 品牌名稱統一為 **聖趣旅遊 FTG TOURS**。
- 嚴格使用「聖」字（Unicode: `U+8056`），絕對禁止使用「塑趣」或「望趣」等早期測試或畫面誤植名稱。

## 2. 視覺精準復刻規範
- 建置或修改 FTG 網站各頁面（首頁、企業員工旅遊、家庭日、ESG戶外團隊日、員工身心平衡、高階主管共識旅程等）時，必須 100% 依據提供的 8 張設計參考圖。
- 區塊順序、標題用詞、卡片數量及小標說明皆須實作完整，不得隨意省略或替換成未經核可的通用文案。

## 3. 中文字型品質守則
- 嚴格檢查所有文案中的易混淆字與簡繁字，例如：「永續」（正確：`U+6C38 U+7E8C`）絕不可寫成「永纆」（`U+7E86`）、「需求訪談」必須使用「談」（`U+8AB1`）。
