# 錯字檢查使用說明

## 什麼是「萮能」錯別字
「萮能」是「萬能」的常見錯別字，發音相似但字形不同。

## 建立背景
2026-07-28 - 在處理「萬能蜂民」清冊時發現「萮能」錯別字重複出現。

## 用法
```bash
# 檢查單個檔案
./scripts/check_typo.sh 蜂民清冊.md

# 檢查多個檔案
./scripts/check_typo.sh file1.md file2.md
```

## 功能說明
- 搜索錯別字「萮能」（應為「萬能」）
- 自動排除註解/備註行中的引用文字（如「*備註：原內容中「萮能」為「萬能」的錯別字」）
- 返回退出碼 0 = clean，1 = 發現錯別字

## 執行結果範例
```
✓  未發現錯別字，檔案 clean
```

或

```
⚠️  發現錯別字「萮能」
應為：萬能
35:*備註：原內容中「萮能」為「萬能」的錯別字，已全數更正*
```
