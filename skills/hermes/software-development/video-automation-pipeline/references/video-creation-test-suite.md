# AI Video Creation Test Suite

## 概述

本測試套件用於驗證AI影片創作流程是否符合品牌標準。目標是在不稀釋原創判斷、不誤導事實、也不犧牲人處境的前提下，將複雜的永續議題蒸餾成觀眻願意看、看得懂、能帶走方法的內容。

## 七道驗證門檻

### Gate 01: 腳本匯入場景生成
**檢查項目**：
- 場景數量（6-16場/分鐘）
- 時間碼無重疊或斷紀
- 場景內容與腳本一致

### Gate 02: 數據圖卡準確性
**檢查項目**：
- 數字與來源資料庫一致
- 年份在合理範圍內（1900-2030）
- 比較方向視覺化清晰
- 來源標籤可點擊查看

### Gate 03: 視覺一致性
**檢查項目**：
- 所有門檻圖卡使用相同配色
- 字體、字型、間距一致
- 圖標風格統一
- 版面布局一致

### Gate 04: AI B-roll人本感
**檢查項目**：
- 人物表情自然、姿態真實
- 種族、年齡、職業背景多元
- 無機器感或不自然光線
- 情感基調溫和、尊重
- 無恐懼或悲情化刻板印象

### Gate 05: 品牌真實感
**檢查項目**：
- 真實人聲比例 ≥ 30%
- B-roll音效比例 ≥ 50%
- 語言風格符合品牌調性

### Gate 06: 子影片切割
**檢查項目**：
- 子影片數量為4支
- 保留原始敘事邏輯
- 門檻圖卡為單一圖片

### Gate 07: 最終定錨驗證
**檢查指標**：
- 觀眻完成率 ≥ 70%
- 事實錯誤率 ≤ 1%
- 人本感評分 ≥ 4/5
- 視覺一致性 ≥ 90%
