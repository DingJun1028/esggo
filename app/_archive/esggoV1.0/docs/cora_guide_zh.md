# Cora (繁體中文版)

一款受 Notion 啟發的 VS Code 知識管理插件，同時為 Cursor / AI
編程場景提供「讀、找、懂、規劃」的配合能力：更好的文件閱讀與導航、項目級代碼理解（CoraWiki，實驗功能）、以及規範的
Plan 書寫（Plan 增強，實驗功能，可選）。

## 為什麼選擇 Cora？

VS Code 和 Cursor 的界面是為編程設計的——左側文件樹、中間編輯器、右側 AI
對話。這種布局對編程很友好，但對知識管理並不理想。

Notion 擅長知識管理：層級頁面、文件大綱、全文搜索。但它缺少 VS Code
強大的編輯能力和 AI 集成。

Cora 將兩者結合。在 Cursor 中使用時，Cora 還協助 AI 更好地理解項目與書寫可執行的
Plan。

- 📁 **頁面樹** —— 層級化的知識組織，像 Notion 一樣直觀
- 📋 **大綱視圖** —— 一鍵導航文件結構，支持層級折疊
- 🔍 **全文搜索** —— 支持多關鍵詞、智能降級搜索
- 📝 **無縫編輯** —— 編輯/預覽一鍵切換，保留 VS Code 原生體驗

## 核心設計理念

保留 VS Code 的編輯能力，增加 Notion 的組織能力。

- 左側面板增加知識庫視圖，隨時可切回原生文件樹
- 中間區域仍用 VS Code 編輯器，預覽/編輯一鍵切換
- 右側 AI 對話保持不變，與知識庫無縫配合

## Cora 與 AI 編程 (主權級協作)

Cora 為 Cursor / AI 編程提供四條能力，讓人與 AI 在同一工作區內更好地協作：

| 能力                | 產品形態                  | 為 AI 編程 / Cursor 帶來的價值                                                                   |
| ------------------- | ------------------------- | ------------------------------------------------------------------------------------------------ |
| **讀 (Read)**       | 頁面樹、大綱              | 更好的 MD/Plan 閱讀與跳轉；AI 引用文件時結構清晰。                                               |
| **找 (Find)**       | 全文搜索                  | 快速定位文件與片段；為 AI 提供「按描述找文件」的前置。                                           |
| **懂 (Understand)** | CoraWiki（實驗功能）      | 理解整倉代碼並生成架構報告；未來通過 MCP 為 Cursor AI 提供更深上下文。                           |
| **規劃 (Plan)**     | Plan 書寫約束（實驗功能） | 寫 Plan 時有結構、可驗收；測試與功能同步開發，每模塊須有單元測試與 e2e，測試通過後才可更新任務。 |

## 使用指南

1. **打開 Cora 面板**
   - 點擊左側活動欄的 📖 **Cora** 圖標
2. **瀏覽文件（頁面樹）**
   - 在【頁面】標籤中查看工作區文件樹；支持**樹狀**、**平鋪**與**收藏**視圖。
3. **查看文件結構（大綱）**
   - 打開任意 Markdown 文件，切換到【大綱】標籤查看標題結構。
4. **搜索筆記**
   - 使用【搜索】標籤，支持多關鍵詞（空格分隔）檢索。
5. **CoraWiki 整合**
   - 進入 CoraWiki 面板，對工作區進行主權級架構分析，產出可供 AI
     讀取的知識圖譜。

## CoraPlan 使用說明 (主權級規劃)

### 模組目的

CoraPlan 採用更有約束的方法論來規範 AI 撰寫計畫 (Plan) 與執行，其核心目標為：

- **減少幻覺**：透過 DDD (領域驅動設計)、TDD (測試驅動開發) 等約定與「完成標準 /
  驗收」前置，約束 AI 輸出更可控、可驗收的計畫。
- **減少人工驗收頻次**：要求測試與功能同步開發，每個模組須具備單元測試與 E2E
  測試。僅當測試全部通過後，才能將任務標記為完成，藉此透過自動化測試降低人工逐項驗收的成本。

> [!TIP]
> 推薦在 Agent 模式下直接讓 AI 根據約束文檔生成 Plan 並執行，避免使用 Cursor
> 內建的 Plan 功能，以確保執行邏輯與 5T 誠信約束一致。

### 如何使用

1. **首次使用**：在 CoraPlan 視圖為空時，點擊 **「在此工作區導入
   CoraPlan」**，系統將自動將約束文檔與範本寫入當前工作區的 `.cursor/plans` 與
   `.cursor/rules` 目錄。
2. **開啟約束說明**：點擊視圖右上角的 **「開啟 Plan 約束說明」**，閱讀
   `00-PLAN-CONSTRAINTS.md`，瞭解如何撰寫 Plan、測試要求與禁止事項。
3. **開啟 README 登記表**：點擊 **「開啟 README 登記表」**，查看或維護 Plan
   文件登記表（包含編號、檔名與簡介）。
4. **撰寫 Plan**：在 Agent 模式下引導 AI 根據約束生成
   `NN-名稱.plan.md`，並在同一對話會話中按 Plan 執行；您亦可在此目錄下手動新建
   Plan 文件，並遵守編號與結構要求。
5. **管理 Plan**：在視圖中點擊 Plan
   文件可開啟編輯；右鍵點擊可進行刪除、複製路徑或在檔案資源管理器中開啟等操作。

### 如何配置

CoraPlan 的能力主要由約束文檔定義，插件本身無需額外配置即可直接使用。

- **界面語言**：在 **設置 → Cora**
  中可設置「界面語言」（預設為繁體中文），這將影響初始狀態介紹與部分 UI 文案。
- **自定義約束**：約束與規則在導入後位於 `.cursor/plans/` 與
  `.cursor/rules/`，您可以直接編輯這些文件以適配團隊的開發習慣。再次點擊導入會覆蓋約束文件，但
  `README` 不會覆蓋已有內容。
