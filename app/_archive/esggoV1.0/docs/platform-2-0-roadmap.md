# ESG GO Platform 2.0: Roadmap & Vision

## Introduction

The goal of Platform 2.0 is to shift from "Platform as a Tool" to "Platform as a
Partner". The **ADK Expert Squad** is the key differentiator, providing
specialized intelligence at every touchpoint.

## Core Experience Principles

1. **Proactive Disclosure**: The AI suggests the next chapter to write based on
   data availability.
2. **Infinite Verifiability**: Every metric points to a cryptographic proof (5T
   Protocol).
3. **Tactical Squad HUD**: Experts are not just features; they are visible,
   active collaborators.

## Technical Architecture (The 2.0 Stack)

- **Brain**: `OmniManager` (Agent 0) + Genkit Multi-Agent Flows.
- **Surface**: Next.js + Framer Motion (vibrant, premium, responsive).
- **Core Utility**: Automated GRI/ESRS Mapping & Audit Readiness.

## The 2.0 User Journey

1. **Landing**: "Omni Command Tray" greets the user with an "Audit Readiness
   Score".
2. **Analysis**: User monitors Scope 3. Agent 0 notices high risk and suggests a
   Supply Chain Chapter.
3. **Generation**: Genkit flows collaborate (Writer + QA) to produce a
   GRI-compliant draft.
4. **Verification**: User clicks "Seal & Archive". System generates a PDF with
   embedded ZK-proofs/Hashes.
