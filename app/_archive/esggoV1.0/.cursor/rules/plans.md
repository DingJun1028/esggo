# CoraPlan 規劃規則 (plans.md)

本規則引導 AI 如何生成高質量的計畫文件。

## 基本準則

1. **模組化思維**：將複雜需求拆解為獨立的、可測試的模組。
2. **驗證優先**：在定義任務時，優先考慮「我如何證明這個任務已完成」。
3. **5T 誠信轉換**：在計畫中體現數據的可追溯性 (Traceable) 與透明度
   (Transparent)。

## Plan 生成提示詞 (Prompt Guidelines)

當用戶要求「寫一個 Plan」時，AI 應：

- 掃描工作區以獲取精確的上下文。
- 根據 `00-PLAN-CONSTRAINTS.md` 的結構生成 Markdown。
- 確保所有測試指令（如 `npm test`、`vitest`）在當前環境下是可執行的。

## 任務登記標準

- `[ ]` 未開始
- `[/]` 執行中 (切換至 EXECUTION 模式)
- `[x]` 已完成且通過測試
