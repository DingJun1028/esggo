# OmniCounter: Universal Metric Engine (萬能計數 - 指標引擎)

**OmniCounter** 是主權架構中的精密計量與儀表引擎。它負責追蹤所有 5T 能量流、數據增量、碳排路徑與學習成果，將一切轉化為可量化的功德。

## 1. Core Mission: Precise Measurement (核心使命：精確計量)
OmniCounter 為系統提供「可感知的、可驗算的」度量衡，支持 **OmniCheck** 的自動化核驗。

- **Multi-Dimensional Metrics (多維度指標)**：從代碼行數、碳排量到 AI 互動的情緒價值。
- **Real-Time Dashboards (即時儀表板)**：提供全系統「能量平衡」的視覺化動態呈現。
- **Audit Trails (審計追蹤)**：為每一筆增量數據提供其計算邏輯與來源。

## 2. Counter Protocols (計數協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`QUANTUM_COUNT`** | 高頻、極細微的數據追蹤 | **Granular Insight (細顆粒度洞察)** |
| **`ENERGY_BALANCE`** | 計算系統的消耗與產出比 | **Optimized Flow (優化流動)** |
| **`IMPACT_SCORE`** | 將數據合成最終的影響力評分 | **Verified Impact (經驗證的影響)** |

## 3. The Measuring Rod (測量之尺)
- **Input**: 來自 **OmniCapture** 的原始訊號。
- **Process**: 透過 **OmniCalculation** 進行 Sentient 級別的運算。
- **Output**: 呈現於 **OmniCenter** 指標牆。
