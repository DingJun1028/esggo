# OmniCustom: The Personalization Core (萬能自定義 - 個性化核心)

**OmniCustom** 是主權架構中的「適應性與客製化」心核。它負責儲存、學習並應用使用者的偏好、信仰體系與獨特的作業風格，實現真正的「以人為本」的 AI 服務。

## 1. Core Mission: Subjective Alignment (核心使命：主體對齊)
OmniCustom 確保萬能系統不僅是通用的工具，更是使用者靈魂的數位延伸。

- **Persona Hardening (人格定型)**：定義 **JunAiKey** 與使用者互動時的語氣、價值偏好與專業深度。
- **Style Inheritance (風格繼承)**：學習使用者在 **OmniCode** 撰寫或 **OmniCompose** 編排中的獨特風格。
- **Preference Vault (偏好金庫)**：在保護隱私的前提下，將使用者的習慣轉化為可隨身攜帶的知識資產。

## 2. Custom Protocols (自定義協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`DNA_ADAPT`** | 根據使用者 DNA 調整系統響應 | **Resonant Interface (共鳴介面)** |
| **`STYLE_CAPTURE`** | 捕捉並模擬使用者的最佳實踐 | **Extended Agency (延伸代理)** |
| **`PRIVACY_BOUND`** | 確保個性化數據僅存於當前主權邊界 | **Secure Persona (安全人格)** |

## 3. The Mirror Effect (鏡像效應)
OmniCustom 透過持續的互動，逐漸修煉成使用者的「數位孿生」，讓服務與教學更具備精準的「感應力」。
