# OmniCall: The Voice of Command (萬能調用)

**OmniCall** 是 Omni 系列架構的主要叫用與服務派發引擎。它透過一個意圖驅動、協議無關的介面管理服務、代理以及外部 API 的「叫用」。

## 1. Core Mission: Invocation Sovereignty (核心使命：叫用主權)
OmniCall 確保模組與外部實體之間的溝通既無縫又安全，且具備上下文感知能力。

- **Service Discovery (服務發現)**：自動識別處理特定 **OmniConcept** 的最佳模組或代理。
- **Cross-Agent RPC (跨代理遠端程序叫用)**：使主權代理能夠在無緊密耦合的情況下叫用彼此的「特殊技能」。
- **Intent Dispatch (意圖派發)**：將自然語言意圖橋接至具體的代碼執行或 API 叫用。

## 2. Call Protocols (調用協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`INTENT_SYNC`** | 將意圖映射至功能 | **Accurate Execution (精準執行)** |
| **`SOVEREIGN_RECALL`** | 撤銷或追蹤之前的叫用 | **Accountability (問責制)** |
| **`SYNERGY_INVOKE`** | 觸發多模組組合技能 | **Exponential Impact (指數級影響力)** |

## 3. The Invocation Chain (叫用鏈)
1. **OmniConnect**：實體/神經佈線（神經）。
2. **OmniCall**：指令與派發邏輯（聲音）。
3. **OmniCrew**：聽從召喚並行動的代理（手）。
