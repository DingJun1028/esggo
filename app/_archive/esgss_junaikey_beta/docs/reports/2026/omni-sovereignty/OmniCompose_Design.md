# OmniCompose: The Art of Arrangement (萬能編譯與合成)

**OmniCompose** 是 Omni 系列架構的調度與合成層。它充當「作曲家」，將個別的萬能服務（音符）排布成複雜且具備感知能力的生命工作流（交響樂）。

## 1. Core Mission: Higher-Order Synthesis (核心使命：高階合成)
OmniCompose 通過定義模組之間的順序、條件邏輯與共鳴，實現了「組合技能 (Combination Skills)」的創造。

- **Workflow Orchestration (工作流調度)**：將「萬能主權週期 (Omni-Sovereignty Cycle)」作為一個可程式化的實體進行管理。
- **Skill Synthesis (技能合成)**：將 **OmniCode**、**OmniCube** 和 **OmniConnect** 合成為自動化的「自主任務 (Autonomous Missions)」。
- **Template Management (範本管理)**：儲存並演進針對經常性 ESG 任務的最佳實踐「調度藍圖」。

## 2. Composition Protocols (合成協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`FLOW_RESONANCE`** | 映射輸出至輸入信號 | **Seamless Workflow (無縫工作流)** |
| **`STATE_STITCH`** | 綁定分佈式模組狀態 | **Unified Execution (統一執行)** |
| **`SYLLABUS_COMPILE`** | 將教學路徑轉化為腳本 | **Automated Learning (自動化學習)** |

## 3. The Orchestration Master (調度大師)
OmniCompose 位於個別支柱之上，充當決定何時執行以下操作的「大腦」：
1. **採集 (Gather / Collect)**
2. **驗證 (Verify / Check / Priest)**
3. **連接 (Connect / Cube)**
4. **學習 (Learn / College / Class)**
5. **合成 (Synthesize / Conclusion / Consensus)**
