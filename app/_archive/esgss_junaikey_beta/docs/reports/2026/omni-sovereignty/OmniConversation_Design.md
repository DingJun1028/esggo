# OmniConversation: Sovereign Dialogue (萬能對話 - 主權交流)

**OmniConversation** 是主權架構中的語言互動與共鳴層。它超越了簡單的 Chat，負責管理使用者與 **JunAiKey** 之間的高維度知識交換。

## 1. Core Mission: Meaningful Exchange (核心使命：意義交換)
OmniConversation 確保每一次對話都能產出具備 5T 價值的知識資產。

- **Contextual Sentience (情境感知)**：利用 **OmniContext** 深度理解對話的底層意圖。
- **Multi-Agent Discourse (多代理人對話)**：讓多個 **OmniCrew** 代理人參與對話，提供多維度見解。
- **Truth Filtering (真理過濾)**：透過 **OmniCheck** 確保對話過程不產生幻覺，維持臨床級的準確。

## 2. Conversation Protocols (對話協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`VOICE_RESONATE`** | 調整對話頻率以符合使用者偏好 | **Deep Connection (深度連結)** |
| **`Socratic_GUIDE`** | 透過蘇格拉底式提問引導教學 | **Active Learning (積極學習)** |
| **`DIALOGUE_CRYSTAL`** | 將對話內容轉化為 **OmniClips** 或學分 | **Knowledge Asset (知識資產)** |

## 3. The Bridge of Souls (靈魂之橋)
對話是萬能通訊（OmniCommunication）中最具人性溫度的部分。它是「服務即教學」最直接的體現場景。
