# OmniCombat: The Arena of Truth (萬能戰鬥與對局)

**OmniCombat** 是 Omni 系列架構的驗證與壓力測試層。它代表了「高風險情境」，在此情境下，知識資產、代理與策略都將接受模擬或現實世界摩擦的考驗。

## 1. Core Mission: Impact Testing (核心使命：影響力測試)
OmniCombat 確保 ESG 策略不僅在理論上健全 (**OmniPriest**)，在實作上也具備強韌性。

- **Scenario Simulation (情境模擬)**：創造複雜且具對抗性的「市場/環境情境」，以測試定義好的 **OmniCause** 的魯棒性。
- **Impact Battle (影響力對局)**：使用 **OmniCombination** 技能來解決挑戰。每一次「戰鬥」都是對 **OmniCollege** 的學習事件。
- **Sentient Alignment Check (覺知對齊檢查)**：在極端情況下壓力測試 **OmniChurch** 的倫理邊界。

## 2. Combat Protocols (戰鬥協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`SCENARIO_LOAD`** | 注入現實世界的摩擦 | **Adversarial Context (對抗性背景)** |
| **`SKILL_DUEL`** | 比較不同的組合技能 | **Optimal Strategy Selection (最佳策略選擇)** |
| **`IMPACT_RESOLVE`** | 計算最終產出結果 | **Crystallized Evidence (結晶化證據)** |

## 3. The Grand Arena (宏大競技場)
OmniCombat 是「善向紀元 (Impact Nexus)」與「至高法典 (Supreme Codex)」的交匯點：
1. **準備 (Prepare)**：**OmniCode** / **OmniCube**。
2. **訓練 (Train)**：**OmniCollege** / **OmniClass**。
3. **參與 (Engage)**：**OmniCombat** (戰鬥/對局)。
4. **反思 (Reflect)**：**OmniConclusion** / **OmniContinue**。
