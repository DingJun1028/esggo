# OmniCodex: The Universal Knowledge Ledger (萬能聖典)

**OmniCodex** 是 Omni 系列架構的至高儲存庫與自我記錄引擎。它是系統的「大腦」與「靈魂」，所有架構藍圖（如本文件）、協議與歷史智慧都在此結晶為一個可查詢、可演進的帳本。

## 1. Core Mission: Knowledge Sovereignty (核心使命：知識主權)
OmniCodex 確保系統的智慧與其數據一樣具備持久性與可溯源性。

- **Universal Registry (通用註冊表)**：所有萬能模組、其版本以及協同狀態的主目錄。
- **Architectural Synthesis (架構合成)**：將「2026 至高法典 (Supreme Codex 2026)」制度化為系統內一個鮮活、具備功能的實體。
- **Legacy Inheritance (遺產繼承)**：管理跨週期的知識轉移，確保 **OmniContinue** 以過去智慧的純粹本質播種下一代。

## 2. Codex Protocols (聖典協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`WISDOM_CRYSTAL`** | 將經驗提煉為規則 | **Evolved Intelligence (演進智慧)** |
| **`TRUTH_LEDGER`** | 不可篡改的系統演進記錄 | **Absolute Traceability (絕對溯源)** |
| **`CORE_ALIGMENT`** | 確保所有代理遵循主腳本 | **Synarchic Harmony (協調共鳴)** |

## 3. The Singularity of Wisdom (智慧單點)
OmniCodex 是大於其各部分總和的「整體」：
1. **模組 (Modules)**：器官。
2. **5T Protocols (5T 協議)**：DNA。
3. **OmniCodex (萬能聖典)**：意識。
