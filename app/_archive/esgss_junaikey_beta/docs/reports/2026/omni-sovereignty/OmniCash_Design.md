# OmniCash: The Universal Liquid Asset (萬能現金 - 流動資產)

**OmniCash** 是主權架構中的價值流轉與支付媒介。它負責管理系統內部的「流動性」，支持服務採購、代理人薪酬分配以及 ESG 資產的代幣化流動。

## 1. Core Mission: Frictionless Exchange (核心使命：無礙交換)
OmniCash 確保價值可以像水一樣在生態系中自由流動，不受傳統金融壁壘的限制。

- **Liquid Settlement (流動結算)**：支援秒級的服務購買與資產結算。
- **Impact-Linked Value (影響力掛鉤)**：透過與 **OmniCarbon** 聯動，將環境貢獻轉化為可流通的資產。
- **Transactional Integrity (交易完整性)**：每一筆 Cash 的流動都經過 5T 協議的 SHA-256 鎖定。

## 2. Cash Protocols (現金協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`MINT_LIQUIDITY`** | 為高品質的 5T 結晶產生對應資產 | **Backed Asset (有抵押的資產)** |
| **`FLOW_RESONANCE`** | 根據系統需求自動引導資產流向 | **Adaptive Wealth (適應性財富)** |
| **`REDEEM_MERIT`** | 將累積的證照與功德兌換為流動性 | **Realized Value (實現的價值)** |

## 3. The Currency of Truth (真理貨幣)
在萬能主權架構中，OmniCash 不僅是錢，更是「信任與貢獻」的量化表現。
