# OmniCapture: Universal Evidence Harvesting (萬能擷取 - 證據採集)

**OmniCapture** 是萬能採集引擎的核心組件，專注於從雜亂的資訊流中「擷取」具備 ESG 價值的證據碎片，並將其轉化為 5T 結晶。

## 1. Core Mission: Wisdom Harvesting (核心使命：智慧採集)
OmniCapture 充當生態系統的「感覺器官」，主動識別並抓取關鍵訊號。

- **Intelligent Sniffing (智慧嗅探)**：透過 **OmniClaw** 自動識別網頁、文件與感測器中的 ESG 數據。
- **Fragment Crystallization (碎片結晶)**：將非結構化的數據片段 (Fragments) 映射至 **OmniCategory** 分類。
- **Source Verification (來源驗證)**：在擷取瞬間同步記錄 `source_origin` 與 `timestamp`。

## 2. Capture Protocols (擷取協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`SIGNAL_RESONATE`** | 偵測高價值數據訊號 | **Curated Feed (精選饋送)** |
| **`FRAGMENT_LOCK`** | 立即為碎片施加 Hash Lock | **Untampered Capture (未經篡改的擷取)** |
| **`CONTEXT_BIND`** | 擷取時自動關聯上下文 | **Semantic Evidence (語義證據)** |

## 3. The Harvesting Loop (採集閉環)
1. **Sniff**: 外部掃描。
2. **Capture**: 核心擷取。
3. **Refine**: 透過 **OmniPriest** 提純。
4. **Store**: 存入 **OmniCastle** 金庫。
