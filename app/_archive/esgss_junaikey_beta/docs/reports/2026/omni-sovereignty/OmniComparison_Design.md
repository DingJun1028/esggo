# OmniComparison: Universal Benchmarking (萬能比較 - 深度標竿)

**OmniComparison** 是主權架構中的標竿分析與比較引擎。它負責將個體或組織的表現與行業標準、競爭對手或歷史最佳實踐進行精準對齊。

## 1. Core Mission: Relational Insight (核心使命：關係洞察)
OmniComparison 幫助使用者在「坐標系」中找到自己的位置，識別差距並尋求卓越。

- **Benchmark Alignment (標竿對齊)**：自動抓取同業龍頭的 ESG 表現並進行 5T 維度的拆解。
- **Cross-Sector Comparison (跨領域比較)**：識別不同服務、不同 **OmniCube** 之間的效能差異。
- **Anomaly Detection (異象偵測)**：透過比較識別出不符合規律的異常數據（可能是幻覺或造假）。

## 2. Comparison Protocols (比較協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`AXIS_SYNC`** | 統一不同數據源的比較基準 | **Fair Benchmarking (公平標竿)** |
| **`GAP_ANALYSIS`** | 識別當前狀態與目標的差距 | **Actionable Logic (可執行的邏輯)** |
| **`RANK_RESONANCE`** | 根據比較結果更新全域排名 | **Competitive Vitality (競爭活力)** |

## 3. The Mirror of Progress (進步之鏡)
比較不是為了製造壓力，而是為了反映真實，引導使用者在「善向永續」的道路上不斷進化。
