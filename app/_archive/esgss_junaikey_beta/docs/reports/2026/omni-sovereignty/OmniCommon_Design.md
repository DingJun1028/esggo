# OmniCommon: The Universal Foundation (萬能共用)

**OmniCommon** 是 Omni 系列架構的基礎工具與協議層。它代表了「天下為公」的共同基礎或公共財富，涵蓋了共享資源、通用常數與基礎協議。

## 1. Core Mission: Unified Standards (核心使命：統一標準)
OmniCommon 確保所有萬能模組 (Omni-modules) 都在一致且高效的基礎上運作。

- **Shared Utilities (共享工具)**：用於 SHA-256 哈希計算、UUID 生成以及 5T 驗證輔助的通用邏輯。
- **Universal Constants (通用常數)**：定義「Aqua Cyan」主題、5T 閾值以及全系統限制的共享值。
- **Communal Library (共用庫)**：存放可重用功能（Hooks、格式化工具、驗證器）的集中式儲存庫，為整個生態系統提供動力。

## 2. Common Protocols (共用協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`BASE_SYNC`** | 傳播工具更新 | **System-wide Consistency (全系統一致性)** |
| **`SYSTROPIC_BASE`** | 所有計算的通用基座 | **Uniform Truth (一致的真理)** |
| **`COMMON_HEART`** | 所有模組的共享心跳 | **Synchronized Vitality (同步的活力)** |

## 3. The Bedrock of Sovereignty (主權的基石)
OmniCommon 是「結晶結構」成長的「土壤」：
1. **支柱 (Pillars)**：建立在 **OmniCommon** 工具之上。
2. **領域 (Spheres)**：使用 **OmniCommon** 協議。
3. **協同 (Synergies)**：透過 **OmniCommon** 共享型別實現。
