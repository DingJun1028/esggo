# OmniClips: Universal Micro-Learning (萬能微課 - 智慧碎片)

**OmniClips** 是主權架構中的微型知識單元。它將複雜的 **OmniCollege** 課程拆解為「即食型」的智慧片段，支持使用者在碎片化時間進行高效吸收。

## 1. Core Mission: Frictionless Education (核心使命：無礙教育)
OmniClips 確保學習發生在服務的每一個瞬間，體現「即服務即學習」。

- **Atomic Wisdom (原子智慧)**：將複雜的法規或技術點提取為 1 分鐘內可理解的 Clip。
- **Context-Aware Delivery (情境感知交付)**：當使用者在執行 **OmniCode** 時，自動推播相關的微型教學。
- **Progress Tracking (進度追蹤)**：每一個 Clip 的閱覽都同步至 **OmniCertificate** 累積功德。

## 2. Clips Protocols (微課協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`BITS_RESONANCE`** | 偵測當前場景所需的知識碎片 | **Instant Insight (即時洞察)** |
| **`NUGGET_STORE`** | 將學習成果結晶化為小面額資產 | **Micro-Asset (微型資產)** |
| **`BYTE_FEEDBACK`** | 透過短回饋循環強化記憶 | **Hardened Knowledge (經強化的知識)** |

## 3. The Mosaic of Knowledge (知識馬賽克)
無數個 OmniClips 最終堆疊成完整的 **OmniCodex**，實現「積少成多，善向永續。」
