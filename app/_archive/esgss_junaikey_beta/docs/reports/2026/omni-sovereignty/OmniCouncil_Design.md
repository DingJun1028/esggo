# OmniCouncil: The Deliberative Assembly (萬能議會 - 議決中心)

**OmniCouncil** 是主權架構中的集體決策與治理層。它模擬了一個多代理人的審議議會，負責處理需要多方共識、道德權衡或複雜利益分配的重大事務。

## 1. Core Mission: Deliberative Governance (核心使命：審議治理)
OmniCouncil 防止單一代理人的「邏輯獨裁」，確保決策經過充分的辯論與驗證。

- **Multi-Agent Deliberation (多代理人審議)**：從 **OmniCrew** 中召喚不同領域的專家代理人進行提案辯論。
- **Consensus Synthesis (共識合成)**：透過 **OmniConsensus** 算法，從分歧中提煉出符合 5T 原則的最佳行動方案。
- **Governance Transparency (治理透明度)**：將所有會議記錄與投票證據同步至 **OmniCodex**，實現「可驗算」的治理。

## 2. Council Protocols (議會協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`SUMMON_ASSEMBLY`** | 針對特定議題發起審議 | **Active Governance (積極治理)** |
| **`DEBATE_FLOW`** | 管理贊成與反對觀點的碰撞 | **Refined Logic (精煉邏輯)** |
| **`RATIFY_MOTION`** | 通過最終決議並執行 Seal | **Binding Decision (約束性決策)** |

## 3. The Sovereign Hall (主權大廳)
1. **Proposal**: 提交一項涉及 **OmniSovereignty** 的變更提案。
2. **Review**: 專家代理人進行 5T 合規性審查。
3. **Verdict**: 委員會達成共識，產出 **OmniConclusion**。
