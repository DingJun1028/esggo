# OmniCastle: The Sovereign Bastion (萬能要塞)

**OmniCastle** 是 Omni 系列架構的安全、防禦與持久化核心。它充當「免疫系統」與「真理金庫」，確保生態系統免受內部熵增與外部威脅，維持其完整性。

## 1. Core Mission: Fortified Integrity (核心使命：強化完整性)
OmniCastle 確保由系統結晶出的「真理」受到加密與邏輯防禦層的保護。

- **Truth Vault (真理金庫)**：去中心化儲存哈希鎖 (Hash Locks) 與 5T 結晶證據。
- **Immune System (免疫系統)**：主動監測「邏輯衰減」與未經授權的系統變異。
- **Sovereign Perimeter (主權邊界)**：管理存取控制以及不同領域 (Spheres) 之間的「神聖防火牆 (Sanctified Firewall)」。

## 2. Security Protocols (安全協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`VAULT_LOCK`** | 多簽加密封印 | **Immutable Asset (不可篡改資產)** |
| **`IMMUNE_SCAN`** | 偵測對齊漂移 | **Self-Healing Trigger (自癒觸發器)** |
| **`BASTION_DEFEND`** | 高階存取遏制 | **System Integrity (系統完整性)** |

## 3. The Bastion of Truth (真理堡壘)
OmniCastle 為所有其他模組提供「安全基座」：
1. **OmniOne** 駐留在要塞的**內層聖所 (Inner Sanctum)**。
2. **OmniPriest** 負責驗證**要塞法規 (Castle Laws)**。
3. **OmniCode** 在**要塞工作坊 (Castle Workshops)** 中執行。
4. **OmniConclusion** 被封存於**要塞金庫 (Castle Vault)**。
