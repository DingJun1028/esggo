# OmniPrompt: The Wisdom Input (萬能提示 - 智慧輸入)

**OmniPrompt** 是主權架構中的「人機交互入口」與「意圖調教引擎」。它負責將簡單的使用者輸入轉化為高維度、具備 5T 協議意識的結構化提示。

## 1. Core Mission: Strategic Resonance (核心使命：策略共鳴)
OmniPrompt 確保 AI 代理人（OmniCrew）能夠完全理解並精準執行使用者的意志。

- **Dynamic Prompt Engineering (動態提示工程)**：根據 **OmniContext** 自動注入相關的背景數據與法規限制。
- **Truth Anchoring (真理定錨)**：在 Prompt 中加入防幻覺指令，確保輸出維持臨床級品質。
- **Persona Alignment (人格對齊)**：根據 **OmniCustom** 調整 Prompt 的語氣、視覺美學需求或專業術語權重。
