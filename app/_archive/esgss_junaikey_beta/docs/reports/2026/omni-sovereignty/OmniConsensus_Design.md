# OmniConsensus: The Harmony of Sovereignty (萬能共識)

**OmniConsensus** 是 Omni 系列架構的協議與驗證層。它確保所有重大行動、數據結晶和狀態轉移都經過多個實體（AI 代理、人類利害關係人以及預言機）的驗證與同意。

## 1. Core Mission: Distributed Agreement (核心使命：分佈式共識)
OmniConsensus 透過要求關鍵系統狀態的多實體驗證，防止「幻覺專制 (Hallucination Autocracy)」。

- **Agent-to-Agent Agreement (代理間協議)**：協調 **OmniCrew** 成員之間的複雜任務。
- **Human-in-the-Loop Validation (人類參與驗證)**：為人類「治理者」提供簽署高影響力決策的介面。
- **Truth Convergence (真理收斂)**：在進入 **OmniConclusion** 之前，將衝突的數據點解析為單一的「結晶化真理」。

## 2. Consensus Protocols (共識協議)
| Protocol | Mechanism | Purpose |
| :--- | :--- | :--- |
| **`MULTI_SIG_VOTING`** | 閾值簽章 (Threshold Signatures) | 授權高風險執行。 |
| **`SENSE_HARMONY`** | NLP 對齊檢查 | 確保 AI 決策符合人類意圖。 |
| **`CONFLICT_RESOLVE`** | 邏輯仲裁 (Logical Arbitration) | 解決神經網絡中的分歧路徑。 |

## 3. The Consensus Bridge (共識橋樑)
OmniConsensus 充當以下各方之間的仲裁者：
- **意圖 (Intention, OmniOne/Priest)**
- **執行 (Execution, OmniCode/Cube)**
- **紀錄 (Recording, OmniInfoCore/Crystal)**

它是將預測轉化為事實的「握手 (Handshake)」。
