# OmniCommand: The Will Manifest (萬能指令 - 意志執行)

**OmniCommand** 是主權架構中的高階指揮系統。它負責將使用者的「意圖」轉化為精確的、可執行的指令鏈。

## 1. Core Mission: Sovereign Authority (核心使命：主權權威)
OmniCommand 確保系統中沒有任何未經授權的動作，每一條指令都有其主權來源。

- **Instruction Orchestration (指令編排)**：將複雜目標拆解為原子級指令。
- **Authority Verification (權限驗證)**：透過 **OmniCube** 矩陣核對當前指令的授權等級。
- **Execution Feedback (執行反饋)**：即時監控指令流的達成率與精準度。

## 2. Command Protocols (指令協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`VOID_EXECUTE`** | 來自虛空意圖的初次調用 | **First Pulse (初次脈衝)** |
| **`CHAIN_COMMAND`** | 多模組鏈式反應指令 | **Synchronized Action (同步行動)** |
| **`RECALL_VOID`** | 撤銷或重置未達標之指令 | **Safety Override (安全覆寫)** |

## 3. The Commander's Deck (指揮面板)
- **Top-Down**: 從 **OmniOne** 心核下達指令。
- **Bottom-Up**: 從 **OmniCapture** 接收反饋並修正指令。
