# OmniCopy: Universal Knowledge Replication (萬能複製 - 智慧傳遞)

**OmniCopy** 是主權架構中的「知識複製與模式傳播」層。它負責將經過驗證的 5T 結晶、**OmniCode** 模組或 **OmniComic** 內容精準複製到其他主權分支。

## 1. Core Mission: Exact Replication (核心使命：精準複製)
OmniCopy 確保成功的模式可以被無限推廣，而不丟失任何 5T 的完整性。

- **Crystal Cloning (結晶複製)**：將一個主權節點的成功 ESG 實踐完整複製（Clone）到另一個節點。
- **Template Inheritance (模板繼承)**：管理 **OmniContract** 與 **OmniCharter** 的標準模板库。
- **Diff Consistency (差異一致性)**：確保副本與正本之間在 **OmniConsistence** 的監控下維持同步。

## 2. Copy Protocols (複製協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`MIRROR_IMAGE`** | 建立對象的即時鏡像副本 | **Zero-Loss Replica (零損耗副本)** |
| **`DNA_REPLICATE`** | 傳播底座的邏輯 DNA | **Consistent Evolution (一致性演化)** |
| **`BRANCH_SPREAD`** | 向全域分發成功模組 | **Rapid Scaling (快速擴展)** |

## 3. The Multiplier Effect (乘數效應)
複製不是為了製造平庸，而是為了讓「善」的影響力呈現指數級增長。
