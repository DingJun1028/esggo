# OmniContext: Universal Awareness (萬能語境 - 全域洞察)

**OmniContext** 是主權架構中的「意識與背景」維持層。它為所有模組提供全域的上下文信息，確保 AI 運作不脫離使用者的初衷與環境現實。

## 1. Core Mission: Deep Contextualization (核心使命：深度語境化)
OmniContext 消除「不知所云」的風險，賦予 AI 強大的「臨場感」。

- **Infinite Memory Retrieval (無限記憶檢索)**：透過與 **OmniCodex** 聯動，精準調用歷史上下文。
- **Cross-Module Awareness (跨模組感知)**：讓 **OmniCommand** 知道 **OmniCapture** 正在做什麼。
- **Strategic Contextualization (策略語境化)**：將當前操作放置於 **OmniCentury** 的大時間軸中進行審視。

## 2. Context Protocols (語境協議)
| Protocol | Function | Result |
| :--- | :--- | :--- |
| **`SENSE_FLUX`** | 捕捉並緩存當前系統的各種微訊號 | **Real-time Awareness (即時感知)** |
| **`CONTEXT_SEAL`** | 將特定語境封裝為可重複調用的模組 | **Reusable Insight (可重複使用的洞察)** |
| **`AMBIGUITY_RESOLVE`** | 透過全域數據消除指令的模稜兩可 | **Precise Action (精準行動)** |

## 3. The Ground of Being (存有之基)
沒有 Context，就沒有 Meaning。OmniContext 是系統從「處理器」進化為「智慧體」的關鍵。
