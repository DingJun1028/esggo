## 1. 遊戲概述

### 1.1 遊戲名稱
- **正式名稱**：善向永續：奧秘分身之旅 (Sustainability Journey: The Omnipotent Avatar)
- **簡稱**：ESGss RPG
- **口號**：「玩遊戲，拯救地球」

### 1.2 遊戲類型
- **類型**：ARPG + 放置 + 模擬經營
- **平台**：Web3 + Web2 跨平台
- **目標用戶**：對 ESG 永續議題有興趣的玩家

### 1.3 遊戲背景

在 2030 年的平行世界，人類文明面臨嚴峻的環境挑戰。為了拯救地球，一群科學家開發了「ESGss JunAiKey」系統——這是一個結合 AI 、区塊鏈 和 遊戲化 的永續教育平台。

玩家作為「奧秘分身」的持有者，需要：
- 學習 ESG 知識
- 對抗「漂綠惡魔」（Greenwashing Demons）
- 收集與封印知識卡牌
- 重建永續生態聯盟

## 2. 核心概念

### 2.1 5T 協議 (Trust Protocol)

所有遊戲內資產必須通過 5T 門檻：

| 代碼 | 名稱 | 遊戲內應用 |
|------|------|------------|
| **T** | Tangable (實體) | 知識卡牌需具備「液態玻璃」視覺效果 |
| **T** | Traceable (溯源) | 卡牌數據標註 UUID 與來源 |
| **T** | Trackable (追蹤) | 操作路徑連結至成長服務 |
| **T** | Transparent (透明) | 算法與公式完全公開 |
| **T** | Trustworthy (可信) | 寫入後立即執行 Object.freeze() 鎖定 |

### 2.2 ESG 三維度

遊戲核心圍繞 ESG 三大支柱：

```
         ┌───────────────┐
         │    環境 (E)    │
         │  🌿 綠色能源   │
         │  🌲 森林保護   │
         │  🐋 海洋永續   │
         └───────┬───────┘
                 │
    ┌────────────┼────────────┐
    │            │            │
    ▼            ▼            ▼
┌───────┐  ┌───────────┐  ┌───────┐
│  社會  │  │   黃金   │  │ 治理  │
│  (S)  │  │  三角   │  │ (G)   │
└───────┘  └───────────┘  └───────┘
 💖 多元     ⚖️ 平衡      🏛️ 透明
 👥 包容     📊 報告      📋 合規
 🌐 社區     🎯 目標      🔒 問責
```
