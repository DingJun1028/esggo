## 一、服務登記總覽

### 1.1 登記原則

本服務登記註冊表遵循 MECE（Mutually Exclusive, Collectively Exhaustive）原則，確保所有服務項目彼此獨立且完整涵蓋 ESG 永續教育平台的全部功能範疇。每項服務都有明確的定義、分類、狀態與負責團隊，建立完整的服務生命週期管理機制。

服務登記的核心價值在於：建立單一事實來源（SSOT），確保所有團隊成員對服務定義有一致的理解；提供服務間的關聯性分析，識別潛在的重疊或缺口；建立服務成熟度追蹤機制，了解各服務的發展狀態；支援服務組合管理，評估資源配置與投資優先順序。

### ESG-01 碳足跡計算器

| 欄位 | 內容 |
|------|------|
| **服務編號** | ESG-01 |
| **服務名稱** | 碳足跡計算器 (Carbon Footprint Calculator) |
| **服務類型** | 分析工具 |
| **所屬類別** | 環境永續 |
| **版本號** | v2.1.0 |
| **狀態** | ✅ 已上線 |
| **負責團隊** | 環境服務團隊 |
| **建立日期** | 2025-06-15 |
| **最後更新** | 2026-01-20 |
| **API 端點** | `/api/v1/carbon-calculator` |
| **相依服務** | 資料收集服務、用戶認證服務 |

**服務描述**：
碳足跡計算器提供企業與個人碳排放量的專業計算功能。系統整合國際溫室氣體核算標準（GHG Protocol），支援範疇一（直接排放）、範疇二（能源間接排放）及範疇三（其他間接排放）的完整計算。使用者可透過輸入能源消耗數據、交通里程、廢棄物處理等資訊，獲得詳細的碳排放報告與減排建議。

**核心功能**：
- 多維度碳排放計算（電力、天然氣、交通、物流）
- 自動映射至科學基礎減量目標（SBTi）
- 歷史趨勢分析與預測
- 同行業基準比較
- 減排行動建議與效益評估

**定價模式**：
- 基礎版：每月 100 次計算，免費
- 專業版：無限制計算，NT$2,000/月
- 企業版：API 整合，NT$15,000/月
