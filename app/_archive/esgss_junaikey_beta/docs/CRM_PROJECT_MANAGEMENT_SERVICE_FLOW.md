## 系統總覽

### 平台定位
CRM 與專案任務管理平台專為 ESG 服務團隊設計，整合客戶關係維護與專案執行追蹤，實現從商機開發到專案交付的一站式管理。

### 核心價值
| 價值主張 | 說明 |
|---------|------|
| **統一平台** | CRM 與專案管理無縫切換，資料互通 |
| **ESG 整合** | 專案對應 ESG 分類，支援永續服務流程 |
| **視覺化管理** | 銷售漏斗、進度圖表、里程碑追蹤 |
| **數據驅動** | 預測成交率、專案效益分析 |

## CRM 客戶關係管理

### 1. 聯絡人管理流程

#### 1.1 新增聯絡人
```
步驟 1: 點擊「新增聯絡人」按鈕
   ↓
步驟 2: 填寫基本資料
   ├─ 姓名 (必填)
   ├─ 職稱
   ├─ 公司名稱
   ├─ Email
   ├─ 電話
   └─ ESG 興趣領域
   ↓
步驟 3: 設定標籤與分群
   ├─ 客戶類型 (企業/政府/非營利)
   ├─ 產業分類
   └─ 標籤 (VIP/策略夥伴/待激活)
   ↓
步驟 4: 儲存並建立互動記錄
```

#### 1.2 聯絡人搜尋與篩選
| 篩選條件 | 說明 |
|---------|------|
| **姓名/公司** | 模糊搜尋 |
| **狀態** | 活躍/非活躍/潛在/流失 |
| **ESG 興趣** | 碳中和/再生能源/TCFD 等 |
| **分數區間** | 0-100 分 |
| **最後聯繫** | 時間範圍 |

#### 1.3 客戶分數計算邏輯

### 2. 商機管理流程

#### 2.1 商機建立
```
步驟 1: 選擇關聯聯絡人
   ↓
步驟 2: 輸入商機基本資訊
   ├─ 商機名稱
   ├─ 預估金額
   ├─ 預期成交日期
   └─ 產品/服務項目
   ↓
步驟 3: 設定銷售階段
   [線索] → [合格] → [提案] → [談判] → [成交/流失]
   ↓
步驟 4: 輸入競爭對手與備註
```

#### 2.2 商機階段說明
| 階段 | 定義 | 成交機率 | 所需動作 |
|------|------|---------|---------|
| **線索 (Lead)** | 初步接觸，有興趣 | 10-20% | 需求訪談、資格審查 |
| **合格 (Qualified)** | 確認需求，符合資格 | 30-40% | 解決方案提案 |
| **提案 (Proposal)** | 已提交方案 | 50-60% | 報價、談判 |
| **談判 (Negotiation)** | 討論合約細節 | 70-80% | 合約審查、法務確認 |
| **成交 (Closed-Won)** | 簽約完成 | 100% | 專案啟動 |
| **流失 (Closed-Lost)** | 未能成交 | 0% | 原因分析、歸檔 |

#### 2.3 加權商機計算
```
加權商機 = Σ(商機金額 × 成交機率)

範例:
├── 台積電碳中和輔導：500萬 × 60% = 300萬
├── 鴻海供應商評估：350萬 × 40% = 140萬
├── 中信金TCFD專案：280萬 × 75% = 210萬
└── 聯電ISO認證：150萬 × 20% = 30萬

加權總額 = 680萬
```

## 專案任務管理

### 1. 專案規劃流程

#### 1.1 新建專案步驟
```
步驟 1: 基本資訊
   ├─ 專案名稱
   ├─ 專案描述
   ├─ 優先權 (緊急/高/中/低)
   └─ ESG 分類 (環境/社會/治理/整合)
   ↓
步驟 2: 時間規劃
   ├─ 開始日期
   ├─ 結束日期
   └─ 里程碑排程
   ↓
步驟 3: 資源配置
   ├─ 預算設定
   ├─ 負責人指派
   └─ 團隊成員邀請
   ↓
步驟 4: 任務分解
   └─ 建立工作分解結構 (WBS)
```

#### 1.2 專案狀態管理
| 狀態 | 說明 | 觸發條件 |
|------|------|---------|
| **規劃中** | 專案籌備階段 | 新建專案 |
| **進行中** | 執行階段 | 開始第一項任務 |
| **暫停** | 暫時停止 | 手動暫停 |
| **已完成** | 全部完成 | 所有任務完成 |
| **歸檔** | 歷史記錄 | 專案結束後 |

### 2. 里程碑管理

#### 2.1 里程碑定義
| 類型 | 說明 | 範例 |
|------|------|------|
| **主要里程碑** | 專案關鍵節點 | 碳盤查完成 |
| **交付里程碑** | 可交付成果 | 報告書初稿 |
| **審查里程碑** | 客戶確認點 | 方案驗收 |

#### 2.2 里程碑狀態
```
待完成 (Pending)     →    進行中 (In-Progress)     →    已完成 (Completed)
         │                        │                        │
    尚未開始                 部分達成                  全部達成
         │                        │                        │
    [灰色標記]              [藍色標記]              [綠色標記]
```

### 3. 任務管理

#### 3.1 任務生命週期
```
┌─────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐
│  待辦   │ → │   進行中    │ → │   審核中    │ → │  已完成  │
│  TODO   │    │ IN-PROGRESS │    │   REVIEW    │    │ DONE    │
└─────────┘    └─────────────┘    └─────────────┘    └─────────┘
      │              │                  │               │
      │              │                  │               │
  指派任務       開始執行           提交審核          驗收通過
```

#### 3.2 任務優先權
| 優先權 | 影響範圍 | 回應時間 | 範例 |
|--------|---------|---------|------|
| **緊急** | 全公司 | 4 小時 | 系統故障、客戶投訴 |
| **高** | 專案延遲 | 24 小時 | 里程碑落後 |
| **中** | 部分影響 | 3 天 | 例行任務 |
| **低** | 無影響 | 1 週 | 優化建議 |

#### 3.3 任務依賴管理
```typescript
// 任務依賴類型
const DEPENDENCY_TYPES = {
    FINISH_TO_START: 'FS',  // A 完成後 B 才能開始
    START_TO_START: 'SS',   // A 開始後 B 才能開始
    FINISH_TO_FINISH: 'FF', // A 完成後 B 才能完成
    START_TO_FINISH: 'SF'   // A 開始後 B 才能完成
};

// 範例
const taskDependencies = [
    { from: 't-001', to: 't-002', type: 'FS' },  // 碳排放收集完成後才能計算
    { from: 't-002', to: 't-003', type: 'FS' },  // 計算完成後才能分析
];
```

### 4. 進度追蹤

#### 4.1 進度計算方式
```
專案進度 = Σ(任務進度 × 任務權重) / Σ(任務權重)

// 預設計務權重 = 預估工時
// 進度範例:
├── 任務 A: 100% × 40 = 40
├── 任務 B:  50% × 60 = 30
├── 任務 C:   0% × 20 =  0
└─────────────────────────────────
專案進度 = 70 ÷ 120 = 58%
```

## 資料模型

### CRM 資料結構
```typescript
interface Contact {
    id: string;
    name: string;              // 姓名
    title: string;             // 職稱
    company: string;          // 公司名稱
    email: string;            // 電子郵件
    phone: string;            // 電話
    industry: string;         // 產業
    segment: 'enterprise' | 'mid-market' | 'smb' | 'government';
    status: 'active' | 'inactive' | 'prospect' | 'churned';
    lastContact: string;      // 最後聯繫日期
    nextFollowUp: string;     // 下次跟進日期
    esgInterest: string[];    // ESG 興趣領域
    lifetimeValue: number;    // 生命週期價值
    score: number;           // 客戶分數 (0-100)
    tags: string[];           // 自訂標籤
    interactions: Interaction[];
}

interface Opportunity {
    id: string;
    name: string;
    contactId: string;
    contactName: string;
    company: string;
    value: number;           // 商機金額
    stage: string;           // 銷售階段
    probability: number;     // 成交機率
    expectedClose: string;   // 預期成交日期
    products: string[];      // 產品清單
    competitor?: string;      // 競爭對手
    notes: string;           // 備註
}
```

interface Project {

    actualHours: number;     // 實際工時
    dependencies: string[];  // 前置任務 ID
    subtasks: SubTask[];
