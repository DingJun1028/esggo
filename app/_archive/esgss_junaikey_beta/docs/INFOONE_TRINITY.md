# InfoOne Trinity Standard (三位一體規範)

**Version**: v1.0.0-Trinity  
**Status**: Core Technical Standard  
**Philosophy**: "One Info, Three Perspectives" (一個資訊，三種視視角)

---

## 1. 概念層面 (Concept Layer) - 整合
**核心目標**: 將碎片化的資料統一成單一 「Info One」 資訊流。

| 項目 | 內容說明 |
| :--- | :--- |
| **定義** | Info One 是一種資訊聚合與呈現的框架，專門用於將分散在多個資料源（文件、資料庫、API、使用者回饋等）中的關鍵資訊統一整理、標記並提供即時檢視。它的設計目標是「一個資訊，三種視角」——同時支援 **結構化**、**半結構化**、與 **非結構化** 資料的無縫整合。 |
| **核心理念** | 1. **資訊統一**：把碎片化的資料統一成單一「Info One」檔案或資料流。<br>2. **層次化**：在同一檔案內保留 **宏觀概覽** 與 **微觀細節** 兩層次。<br>3. **可擴展**：支持插件化的「三位一體」處理模組（概述、分析、可視化），可根據需求自由拼湊。 |
| **基本構成** | - **資訊核心 (Core Info)**：不可變的核心資訊（如唯一識別碼、時間戳、關鍵詞）。<br>- **補充層 (Enrichment Layer)**：可選的延伸資訊（情感分析、關係圖、統計指標）。<br>- **呈現層 (Presentation Layer)**：依照使用者需求輸出為文字、圖表或交互式 UI。 |

## 2. 功能層面 (Function Layer) - 解析
**核心目標**: 提供 「概述-細節-延伸」 的同步處理能力。

| 功能 | 說明 | 為什麼「三位一體」 |
| :--- | :--- | :--- |
| **整合** | 從多渠道抓取（API、CSV、JSON、HTML、文字）合併資料，自動對齊欄位與類型。 | 同一筆資訊在 「原始」、「清洗」、「豐化」 三種階段同時保留。 |
| **解析** | 產生結構化的 「資訊樹」：根節點（Info One 主題） → 分支（子主題） → 子節點（屬性）。 | 同一資訊同時呈現 「概述」（層級1）、「細節」（層級2）與 「延伸」（層級3）。 |
| **分析** | 內建 NLP、關係抽取、時序分析 模組，可即時產生摘要、關鍵字、相似度、情感值等指標。 | 同時提供 「文字摘要」、「關係圖」、「圖表」 三種可視化方式。 |
| **呈現** | 支援 內建視覺化、API 輸出、桌面/瀏覽器 UI 三種展示形式。 | 讓不同角色（管理者、分析師、普通使用者）分別取得「總覽」/「細節」/「導出」三種資訊。 |

## 3. 應用層面 (Application Layer) - 呈現
**核心目標**: 讓不同角色在同一流程中獲取所需資訊。

### 實務示範：企業客戶滿意度調查
1. **收集**：把線上問卷、電話錄音、社交媒體貼文三種資料同時匯入 Info One，形成 **三個資料流**。
2. **清洗 & 標記**：同一筆回應在 「原始」（原始文字） → 「清洗」（去噪、分詞） → 「標記」（情感、主題標籤） 三層次同時處理。
3. **建模**：使用 Info One 的 「關係抽取」 模組，產生 「顧客情緒-主題圖」，同時在 「概述」 層顯示整體滿意度分布、「細節」 層展示各子主題佈局、「延伸」 層提供時間變化趨勢圖。
4. **可視化**：依照使用者角色自動切換展示：
    - 管理層 → 「總覽」 圖表（瀏覽式儀表板）
    - 客服主管 → 「細節」 文字摘要＋關係圖
    - 研發團隊 → 「延伸」 演算法指標與 CSV 導出。
5. **決策**：依照三位一體的多面向資訊，快速定位問題根源、評估干預效果，並產出 「決策報告」（三頁：概括、關鍵洞察、行動建議）。

---

> [!IMPORTANT]
> **三位一體的核心**：讓使用者能夠 **「一眼看到全貌、一層一層深入、立刻採取行動」**。
