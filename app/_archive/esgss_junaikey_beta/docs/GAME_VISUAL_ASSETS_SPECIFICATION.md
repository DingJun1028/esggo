# 善向永續村遊戲視覺素材規範
# ESGSS JunAiKey Sustainability Village Game Visual Assets Specification

## 總覽 Overview

本文檔詳細描述了善向永續村遊戲所需的10張視覺圖像的設計規範。每張圖像都承載著獨特的遊戲角色、場景或界面元素，旨在增強玩家的沉浸感和遊戲體驗。

所有圖像均採用統一的設計語言，融合東方水墨美學與現代幻想藝術風格，營造出既神聖又親切的視覺氛圍。

## 詳細設計規範 Detailed Design Specifications

### 01. 綠色守護者 Forest Guardian

#### 基本資訊
- **名稱**: 綠色守護者 (Green Guardian)
- **稱號**: 森林之心 (Heart of the Forest)
- **元素屬性**: 木元素
- **擅長領域**: 環境保護、生態保育、碳匯森林
- **戰鬥風格**: 輔助治療、自然控制

#### 視覺設計
**整體輪廓**：
呈現為一位婀娜多姿的女性守護者，身高約170公分，體態輕盈飄逸。服裝以多層次綠色系為主，由深至淺呈現層次感，象征森林的垂直結構。

**服裝設計**：
- 上身為交領深綠色長袍，袖口和領口點綴金色邊紋，象征陽光穿透樹冠
- 腰繫翡翠綠絲帶，絲帶末端延伸出藤蔓般的裝飾紋路
- 下半身裙擺採用荷葉邊設計，行走時如落葉飄舞
- 頭戴由鮮花和樹枝編織的花環，花環中央鑲嵌發光的綠色水晶

**髮型與面容**：
- 長髮如瀑布般垂落，髮色為深褐色帶有綠色光澤
- 髮絲間穿插著小小的發光粒子，模擬森林中的螢火蟲
- 面容祥和閉眼，嘴角微笑，雙手合十呈祈禱姿態

**配件與道具**：
- 右手握持由活木製成的法杖，法杖頂端生長著發光的嫩葉
- 法杖周圍環繞著飄浮的綠色光點，代表自然能量
- 左手腕佩戴藤蔓編織的手環，鑲嵌綠色寶石
- 腰間懸掛由樹葉製成的小袋，內含種子

**色彩規範**：
| 元素 | 色碼 | 用途 |
|------|------|------|
| 主色 | #228B22 | 森林綠 - 服裝主體 |
| 副色 | #32CD32 | 萊姆綠 - 發光效果 |
| 強調色 | #FFD700 | 金色 - 邊紋裝飾 |
| 輔助色 | #8B4513 | 棕色 - 木質元素 |
| 背景色 | #F0FFF0 | 蜂蜜綠 - 柔和背景 |

**光影效果**：
- 全身籠罩在柔和的翠綠光芒中
- 發光粒子從法杖頂端向外擴散
- 邊緣使用半透明光暈處理，模擬精靈般的氣質

**背景場景**：
- 置身於古老森林深處，陽光透過茂密樹冠形成光柱
- 背景可見模糊的巨樹輪廓和飄落的紅葉
- 地面鋪滿苔蘚和落葉，點綴白色野花
- 遠處有鹿群剪影，增添生機

**動畫幀建議**：
1. 待機狀態：髮絲和衣袂輕微飄動，法杖光芒脈動
2. 攻擊動作：法杖向前指，光點如箭般射出
3. 治療動作：雙手張開，綠色能量如漣漪般擴散
4. 勝利動作：花環發出耀眼光芒，森林背景變得明亮

### 02. 海洋女王 Ocean Queen

#### 基本資訊
- **名稱**: 海洋女王 (Ocean Queen)
- **稱號**: 深藍之心 (Heart of the Deep Blue)
- **元素屬性**: 水元素
- **擅長領域**: 海洋保育、水資源管理、循環經濟
- **戰鬥風格**: 範圍攻擊、持續輸出

#### 視覺設計
**整體輪廓**：
呈現為一位威嚴而優雅的海洋统治者，身高約175公分，姿態挺拔有力。整體形象結合人類女性的上半身和魚類的尾鰭，展現神話生物的奇幻美感。

**上半身設計**：
- 穿著深藍色與青色交織的鱗片盔甲，鱗片由淺至深漸變
- 盔甲表面有珍珠母般的光澤反射
- 領口設計如波浪翻湧的形狀，鑲嵌藍寶石
- 胸部區域有海藻紋身的藝術設計

**下半身設計**：
- 從腰部向下延伸為巨大的扇形尾鰭
- 尾鰭呈半透明深藍色，有明顯的骨骼紋路
- 尾鰭邊緣裝飾著發光的白色邊線
- 行走時尾鰭如波浪般優雅擺動

**髮型與面容**：
- 長髮呈現深藍至青色漸變，如海底瀑布般流淌
- 髮絲中夾雜著小小的氣泡和發光水母
- 面容高貴威嚴，雙眼如深海般神秘
- 頭戴由珊瑚和珍珠製成的王冠

**配件與道具**：
- 右手握持三叉戟，戟身由深海金屬打造，頂端鑲嵌巨型藍寶石
- 三叉戟周圍環繞著旋轉的水流光環
- 左手佩戴由貝殼製成的手套，指尖發出微光
- 頸戴由珍珠和藍寶石串成的項鏈

**色彩規範**：
| 元素 | 色碼 | 用途 |
|------|------|------|
| 主色 | #006994 | 海洋藍 - 鱗片盔甲 |
| 副色 | #00CED1 | 綠松石 - 尾鰭漸變 |
| 強調色 | #E0FFFF | 亮青色 - 發光效果 |
| 輔助色 | #191970 | 午夜藍 - 深色區域 |
| 背景色 | #001F3F | 深海藍 - 背景 |

**光影效果**：
- 全身籠罩在水元素能量場中，呈現夢幻的藍綠色光暈
- 水流如絲帶般環繞身體，緩慢流動
- 鱗片盔甲有珠寶般的閃爍效果
- 三叉戟發出的光芒穿透水面

**背景場景**：
- 置身於海底宮殿前，周圍是發光的珊瑚礁
- 各種熱帶魚群在背景中游動
- 從上方灑落的陽光形成夢幻的光柱
- 海床鋪滿細軟的白色沙粒

**動畫幀建議**：
1. 待機狀態：尾鰭輕輕擺動，髮絲如海草般漂浮
2. 攻擊動作：三叉戟向前刺出，引發巨大水柱
3. 特殊技能：全身被巨大水泡包裹，隨後爆發
4. 勝利動作：海豚群躍出水面慶祝

### 03. 山嶽守護者 Mountain Guardian

#### 基本資訊
- **名稱**: 山嶽守護者 (Mountain Guardian)
- **稱號**: 大地之子 (Son of the Earth)
- **元素屬性**: 土元素
- **擅長領域**: 地質保育、水土保持、綠色建築
- **戰鬥風格**: 防禦反擊、持久作戰

#### 視覺設計
**整體輪廓**：
呈現為一位魁梧雄壯的男性守護者，身高約190公分，體格健碩如山巖。整體形象如同從山體中誕生的岩石巨人，散發著穩重與力量。

**服裝設計**：
- 穿著由深灰色岩石紋理 armour，armour 表面有不規則的裂紋和礦脈紋路
- armour 關節處使用青銅色金屬連接，模擬古代青銅器風格
- 肩甲設計成山峰形狀，頂端覆蓋苔蘚和小型灌木
- 腰間繫著獸皮製成的腰帶，掛有各種工具

**腿部設計**：
- 小腿被同材質的護甲覆蓋，護甲呈現層疊岩層結構
- 靴子設計成厚重的登山靴造型，靴底有深深的防滑紋路
- 靴面有金屬扣環固定，展現實用性

**面容與髮型**：
- 面容剛毅端正，有歲月刻畫的皺紋，如同風化的岩石
- 眉毛濃密如山脊，雙眼如深潭般沉穩
- 頭髮灰白相間，剪短但略顯凌亂
- 臉頰和下巴有短短的鬍渣

**配件與道具**：
- 雙手佩戴岩石拳套，拳套表面有尖銳的晶體突出
- 背後背著巨大的岩石盾牌，盾面刻有古老的山岳符文
- 腰間掛著採礦鎬和繩索
- 頭頂有一隻小型禿鷲棲息，代表山岳的信使

**色彩規範**：
| 元素 | 色碼 | 用途 |
|------|------|------|
| 主色 | #696969 | 岩石灰 -盔甲主體 |
| 副色 | #8B4513 | 皮革棕 -皮帶配件 |
| 強調色 | #DAA520 | 金銅色 -金屬連接 |
| 輔助色 | #556B2F | 苔蘚綠 -點綴元素 |
| 背景色 | #2F4F4F | 深岩灰 -背景 |

**光影效果**：
- 整體呈現厚重的實體感，邊緣銳利明確
- armour 表面有陽光照射產生的高光和陰影對比
- 偶爾有石屑或光點從 armour 表面脫落
- 眼神中閃爍著智慧的光芒

**背景場景**：
- 置身於巍峨山脈之前，山峰被雲霧繚繞
- 背景可見高山草甸和滑雪道
- 山腳下有村莊和梯田，展現人與山的和諧
- 遠處積雪的山峰在陽光下閃閃發光

**動畫幀建議**：
1. 待機狀態：身體隨呼吸微微起伏，偶有石屑掉落
2. 防禦動作：舉起盾牌，岩石紋路發出光芒
3. 攻擊動作：岩石拳套揮出，伴隨碎石飛濺
4. 特殊技能：大地裂開，從中湧出土元素能量
