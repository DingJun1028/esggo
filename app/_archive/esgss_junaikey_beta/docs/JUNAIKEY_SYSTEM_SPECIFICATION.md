## 一、系統總覽

### 1.1 系統願景

ESGss JunAiKey Beta 是一個以「服務即教學，知識即資產」為核心理念的 ESG 永續教育平台。系統透過人工智慧技術，將複雜的 ESG 知識轉化為可操作的服務，讓使用者在使用平台的過程中自然吸收永續知識，累積為個人智慧資產。

系統的兩大核心支柱為：ESG 永續服務（24 項 MECE 服務）與 JunAiKey 萬能精靈（AI 知識傳授系統）。兩者相互融合，形成「服務中學習，學習中服務」的獨特體驗。

### 1.2 系統架構

```
┌─────────────────────────────────────────────────────────────────┐
│                      ESGss JunAiKey Beta                         │
├─────────────────────────────┬───────────────────────────────────┤
│    ESG 永續服務層 (24項)     │      JunAiKey 知識傳授層          │
│  ┌─────────────────────┐   │   ┌─────────────────────────┐     │
│  │ 環境永續 (8項)       │   │   │ 萬能精靈 AI 助手         │     │
│  │ 社會責任 (8項)       │   │   │ 知識聖殿                 │     │
│  │ 公司治理 (8項)       │   │   │ 學習 Alchemy            │     │
│  └─────────────────────┘   │   │ 典範報告服務              │     │
│                            │   │ Berkeley 認證學院         │     │
├─────────────────────────────┴───────────────────────────────────┤
│                      5T 信任協議層                               │
│  Traceable │ Trackable │ Transparent │ Trustworthy │ Tangible  │
├─────────────────────────────────────────────────────────────────┤
│                      基礎設施層                                  │
│  React + TypeScript │ Node.js │ PostgreSQL │ AI Services       │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 核心原則

**5T 協議**：系統所有功能皆遵循 5T 信任協議，確保資訊的可追溯性、可追蹤性、透明度、值得信賴性與有形價值。

**NIRVA² 框架**：系統基於 NIRVA² 框架設計，實現無縫接軌（Seamless Integration）與永續價值創造（Sustainable Value Creation）。

## 二、JunAiKey 萬能精靈系統

### 2.1 系統概述

JunAiKey 萬能精靈是 ESGss 平台的核心 AI 助手，肩負「知識傳授」與「服務引導」雙重使命。透過自然語言對話，JunAiKey 能夠理解使用者的 ESG 學習需求，引導其使用適當的服務，並在過程中提供知識講解與學習建議。

| 屬性 | 內容 |
|------|------|
| **系統名稱** | JunAiKey 萬能精靈 |
| **角色定位** | ESG 知識導師、服務導航員 |
| **核心能力** | 自然語言理解、知識問答、服務推薦、學習引導 |
| **技術基礎** | GPT-4 / Claude 3 + RAG 增強 |
| **互動形式** | 對話式介面 + 視覺化回饋 |

### 2.2 核心功能模組

#### 2.2.1 智能對話引擎

| 功能 | 說明 |
|------|------|
| **自然語言理解** | 支援繁體中文、英文、日文多語言對話 |
| **意圖識別** | 準確識別使用者學習意圖與服務需求 |
| **上下文記憶** | 維持對話連續性，記錄學習歷程 |
| **情感感知** | 偵測使用者情緒，調整回應風格 |
| **多輪對話** | 支援複雜問題的逐步引導與解答 |

#### 2.2.2 知識問答系統

| 功能 | 說明 |
|------|------|
| **ESG 知識庫** | 整合環境、社會、治理三大領域知識 |
| **即時檢索** | 基於 RAG 的即時知識檢索與生成 |
| **來源引用** | 所有回答標註知識來源，支援 5T 協議 |
| **深入講解** | 依據使用者程度調整解說深度 |
| **知識關聯** | 主動推薦相關知識主題 |

#### 2.2.3 服務推薦引擎

| 功能 | 說明 |
|------|------|
| **需求分析** | 分析使用者描述，推薦合適服務 |
| **智能路由** | 將複雜需求分流至專業服務模組 |
| **使用引導** | 提供服務操作步驟與注意事項 |
| **成效追蹤** | 記錄服務使用結果，優化推薦策略 |

#### 2.2.4 學習路徑規劃

| 功能 | 說明 |
|------|------|
| **能力評估** | 評估使用者 ESG 知識水平 |
| **目標設定** | 協助設定個人化學習目標 |
| **路徑生成** | 規劃客製化學習路徑 |
| **進度追蹤** | 記錄學習里程碑與成果 |
| **調整優化** | 根據表現動態調整學習計畫 |

### 2.3 對話腳本系統

JunAiKey 內建多元化的對話腳本，針對不同情境提供專業且溫暖的回應。

| 腳本類型 | 用途 | 範例情境 |

## 七、5T 信任協議系統

### 7.1 協議概述

5T 協議是 ESGss 平台的核心信任機制，確保所有資訊與服務的 Traceable（可追溯）、Trackable（可追蹤）、Transparent（透明）、Trustworthy（值得信賴）、Tangible）。

| 協議 | 色彩 | 色碼 | 功能 |
|------|------|------|------|
| Traceable | 青色 | #00BCD4 | 資訊溯源 |
| Trackable | 靛藍 | #3F51B5 | 狀態追蹤 |
| Transparent | 淺綠 | #8BC34A | 透明公開 |
| Trustworthy | 金色 | #FFC107 | 信譽認證 |
| Tangible | 橙紅 | #FF5722 | 價值量化 |

### 7.2 Traceable 可追溯

| 功能 | 說明 |
|------|------|
| **來源追蹤** | 所有資訊標註原始來源 |
| **版本紀錄** | 每次更新都有版本紀錄 |
| **修改歷史** | 保留完整修改歷史 |
| **引用網路** | 知識間的引用關聯 |

### 7.3 Trackable 可追蹤

| 功能 | 說明 |
|------|------|
| **進度追蹤** | 學習進度、服務使用進度 |
| **狀態監控** | 任務執行狀態即時更新 |
| **歷史紀錄** | 完整操作與使用歷史 |
| **趨勢分析** | 歷史數據趨勢視覺化 |

### 7.4 Transparent 可透明驗算

| 功能 | 說明 |
|------|------|
| **演算法透明** | 推薦與評分邏輯公開 |
| **定價透明** | 服務定價與計費方式透明 |
| **數據透明** | 使用數據與分析方式說明 |
| **決策透明** | 重要決策與依據公開 |

### 7.5 Trustworthy 不可篡改

| 功能 | 說明 |
|------|------|
| **專家認證** | 知識內容經專家審核 |
| **使用者評價** | 真實使用者評價系統 |
| **準確性驗證** | 事實查核與準確率追蹤 |
| **安全認證** | 資訊安全與隱私保護認證 |

### 7.6 Tangible 可感知

| 功能 | 說明 |
|------|------|
| **學習成果** | 具體的知識與技能提升 |
| **證書資產** | 可驗證的數位證書 |
| **量化指標** | 可量化的 ESG 績效 |
| **價值轉換** | 知識轉化為實際價值 |
