## Overview

The JunAiKey system integrates **Snyk** as its primary security engine, orchestrated by the **AICoordinationService**. This enables the system to not only find vulnerabilities but also to "reason" about them using Gemini and Ollama.

### Level 2 Continuous AI

By combining the Continue CLI with our security services, you achieve **Level 2 Continuous AI**:

- **Autonomous Detection**: Security scans run on every PR.
- **AI Remediation**: The setup automatically generates fix proposals.
- **Human-in-the-Loop**: Developers review and approve the AI-generated PR comments.

---

## Prerequisites

- Snyk CLI installed and authenticated (`snyk auth`).
- Environment variables `VITE_SNYK_ORG_ID` and `VITE_SNYK_API_TOKEN` configured.
- Continue CLI (`cn`) installed.

---

## Documentation Workflows

### 🔍 Running a Semantic Security Analysis

Use the internal `AICoordinationService` to perform a "Triple-AI" analysis (Snyk + Gemini + Ollama).

**Prompt:**

```bash
"Run a full security analysis using the internal AICoordinationService.
Summarize the top 3 high-risk vulnerabilities and explain how they impact
our ESG compliance goals."
```

### 🛠️ Automated Fix Generation

The `AICoordinationService` can generate specific remediation steps derived from local knowledge bases.

**Prompt:**

```bash
"For the vulnerability [CVE-ID], use the generateRemediation method
to find the best fix based on our internal security best practices.
Propose a diff for the affected package.json or source file."
```

## CI/CD Integration: Continuous Security

The system includes a pre-built GitHub Action that automates this entire flow.

### Setup Workflow

1. Add `SNYK_TOKEN` and `CONTINUE_API_KEY` to your GitHub Secrets.
2. The workflow in `.github/workflows/snyk-continuous-ai.yml` will automatically:
   - Identify changed files.
   - Run `snyk code test`.
   - Use `cn` to post specialized remediation advice as PR comments.

```yaml
# Example usage in PR
'Scan this PR for new vulnerabilities and provide AI-powered mitigation steps.'
```
