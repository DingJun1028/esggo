# Continue Autocomplete 快速入門 (Quick Start)

> 了解如何在 IDE 中快速開始使用 Continue 的 AI 自動補全 (Autocomplete)，包括啟用行內代碼建議以及用於接受、拒絕或部分接受補全的鍵盤快捷鍵。
> Learn how to quickly start using Continue's AI autocomplete in your IDE, including enabling inline code suggestions and keyboard shortcuts for accepting, rejecting, or partially accepting completions.

## 如何啟用與使用 Continue Autocomplete (How to Enable and Use)

自動補全在您輸入時提供行內代碼建議。要啟用它，只需點擊 IDE 右下角狀態欄中的 "Continue" 按鈕，或確保 IDE 設置中已勾選 "Enable Tab Autocomplete" 選項。
Autocomplete provides inline code suggestions as you type. To enable it, simply click the "Continue" button in the status bar at the bottom right of your IDE or ensure the "Enable Tab Autocomplete" option is checked in your IDE settings.

## 自動補全快捷鍵 (Keyboard Shortcuts for Autocomplete)

### 接受完整建議 (Accept a Full Suggestion)

按 `Tab` 鍵接受完整建議。
Accept a full suggestion by pressing `Tab`.

### 拒絕完整建議 (Reject a Full Suggestion)

按 `Esc` 鍵拒絕完整建議。
Reject a full suggestion with `Esc`.

### 部分接受建議 (Partially Accept a Suggestion)

如需更精細的控制，請使用 `cmd/ctrl` + `→` 逐字接受建議的部分內容。
For more granular control, use `cmd/ctrl` + `→` to accept parts of the suggestion word-by-word.

### 強制觸發建議 (Force a Suggestion - VS Code)

如果您想立即觸發建議而不想等待，或者如果您已關閉建議並想要一個新的建議，可以使用快捷鍵 **`cmd/ctrl` + `alt` + `space`** 強制觸發。
If you want to trigger a suggestion immediately without waiting, or if you've dismissed a suggestion and want a new one, you can force it by using the keyboard shortcut **`cmd/ctrl` + `alt` + `space`**.
