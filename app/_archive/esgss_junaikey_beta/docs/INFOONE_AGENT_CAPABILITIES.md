# InfoOne Agent Capabilities (Agent 能力規範)

**Version**: v1.0.0-Agent  
**Role**: Information Mediator (智慧型資訊中介)  
**Core Five**: 資料抓取、解析、分析、呈現、互動

---

## 1. 概念層面 (Concept Layer)
| 項目 | 說明 |
| :--- | :--- |
| **定位** | Info One Agent 同時具備 資料抓取、解析、分析、呈現與互動 五大核心功能。 |
| **角色** | - **資訊探員**：在多源資料之間建立映射與對應。<br>- **問題解說者**：把原始資料轉換成使用者易懂的摘要與洞察。<br>- **決策輔助者**：根據事先設定的邏輯或模型提供建議與預測。 |
| **運作模式** | 主動偵測 → 資料聚合 → 深度處理 (NLP/關係抽取/情感分析/時序預測) → 實時回饋 (文字/圖表/API)。 |

## 2. 功能層面 (Function Layer)
| 能力類別 | 具體功能 | 為「三位一體」映射的意義 |
| :--- | :--- | :--- |
| **整合** | 多源資料併載 (API, CSV/JSON, Web Scrape, DB, OCR)。自動 Schema 校驗與對齊。 | 同一筆資訊在 「原始」 → 「清洗」 → 「豐化」 三層同步呈現。 |
| **解析 & 建模** | 自然語言理解 (NLP)、結構化建模 (資訊樹/關係圖)、機器學習預測 (異常偵測/分類)。 | 同時提供 「概述」（主題層級）、 「細節」（關係/屬性層級）與 「延伸」（統計/預測層級）。 |
| **呈現 & 回饋** | 多媒體視覺化 (Sankey, 熱力圖, 詞雲)、介面自適應、互動式對話。 | 生成的資訊在 「總覽」（儀表板）、「細節」（鑽取）以及 「導出」（API/CSV/報表） 三種形式同時可得。 |
| **持續學習** | 模型微調、策略切換、記憶體系。 | 讓「概念」層面在實務上表現為 「演化」、「適適應」、「持續改進」。 |

## 3. 核心能力清單 (Core Capabilities List)
- **多源資料抓取與結構化**：API、資料庫、檔案、Web Scrape、OCR、語音轉文字。
- **自動欄位對齊與型別轉換**：智慧 Schema 推導、缺值插補、異常值偵測。
- **自然語言處理套件**：分詞、句法分析、主題抽取、情感極化、關鍵字抽出。
- **資訊樹 & 關係圖生成**：以圖形化方式呈現層級關係、實體抽取與節點連結。
- **即時分析模組**：時序預測、分類、回歸、聚類、異常偵測、指標計算。
- **多媒體視覺化**：動態圖表、Sankey、熱力圖、詞雲、儀表板。
- **介面適配與回饋**：文字回覆、JSON API、Web Dashboard、桌面小工具、語音輸出。
- **互動式深入探詢**：追問、說明、假設測試、結果可視化。
- **持續學習與模型自適應**：使用者回饋微調、策略切換、歷史記憶保留。
- **決策輔助流程**：自動生成「總結報告」→「關鍵洞察」→「行動建議」三層決策文件。
