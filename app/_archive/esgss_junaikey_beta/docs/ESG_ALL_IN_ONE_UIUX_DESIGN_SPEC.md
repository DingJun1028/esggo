# ESGss JunAiKey Beta UI/UX 設計規範
## Pencil 設計參考指南

**設計風格**：一頁固定便當盒密集資訊式 (Bento Grid Dense Info Layout)  
**響應策略**：自適應全響應 (Adaptive Full Responsive)  
**設計系統**：Material-UI 7 + 自定義 ESG 主題  
**多語系支援**：繁體中文 (預設)、English、日文、韓文  
**主題系統**：上善若水版 (預設)、日光版、夜晚版、主題皮膚版  

---

## 📐 設計原則

### 1. 便當盒式佈局 (Bento Grid Layout)
- **定義**：將頁面分割為多個獨立的「便當盒」區塊，每個區塊承載特定功能或資訊
- **優勢**：模組化、可組合、資訊密度高、視覺整潔
- **適用場景**：儀表板、知識總覽、報告書編輯頁面

### 2. 密集資訊呈現
- **原則**：在有限空間內呈現最多相關資訊
- **技巧**：
  - 使用階層式標題結構
  - 採用卡片式設計區隔資訊
  - 運用圖示與色彩编码
  - 支援展開/收合詳細資訊

### 3. 自適應響應策略
| 斷點 | 視窗寬度 | 便當盒佈局 |
|------|----------|------------|
| XS | < 600px | 單列堆疊，每個便當盒佔滿寬度 |
| SM | 600px - 960px | 雙列佈局 |
| MD | 960px - 1280px | 三列佈局 |
| LG | 1280px - 1920px | 四列便當盒網格 |
| XL | > 1920px | 五列寬幅便當盒 |

## 📱 組件設計規範

### 1. 便當盒卡片 (BentoCard)

```tsx
// 便當盒卡片基本結構
<BentoCard
  title="知識標題"
  subtitle="副標題說明"
  icon={<ESGIcon />}
  status="active" // active, warning, error, neutral
  expandable={true}
  gridSpan={2} // 佔據格數 (1-4)
  onAction={() => {}}
>
  {/* 卡片內容區域 */}
  <CardContent>
    {/* 密集資訊呈現區域 */}
  </CardContent>
</BentoCard>
```

**設計規範**：
- **圓角**：8px
- **陰影**：輕微陰影 (elevation 2)，懸停時提升 (elevation 4)
- **內邊距**：16px
- **間距**：便當盒間距 16px
- **邊框**：1px solid rgba(0,0,0,0.08)
- **背景**：白色或淺灰 (#FAFAFA)

### 2. 密集資訊網格 (DenseInfoGrid)

```tsx
<DenseInfoGrid
  columns={4} // 響應式自動調整
  gap={8}
  itemMinWidth={120}
>
  <InfoCell
    label="標籤"
    value="數值"
    trend="up" // up, down, stable
    color="E" // E, S, G, Neutral
  />
  {/* 重複多個 InfoCell */}
</DenseInfoGrid>
```

**設計規範**：
- **標籤字體**：12px, #666, Medium
- **數值字體**：16px, #333, Bold
- **趨勢指示**：向上箭頭(綠)、向下箭頭(紅)、水平線(灰)
- **最小尺寸**：120px x 80px

### 3. 進度環 (ProgressRing)

```tsx
<ProgressRing
  value={75}
  max={100}
  label="完成率"
  size={80}
  strokeWidth={6}
  color="primary" // primary, E, S, G
  showValue={true}
  subtitle="75/100 項目"
/>
```

### 4. 狀態徽章 (StatusBadge)

```tsx

  status="verified" // pending, verified, expired, warning
  size="small" // small, medium, large
  icon={<CheckIcon />}
```
