#### 1.1 API Rate Limiting
```typescript
// 實作 express-rate-limit
import rateLimit from 'express-rate-limit';

const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 分鐘
  max: 100 // 限制 100 個請求
});

app.use('/api/', apiLimiter);
```

- 為 `GovernanceService` 添加 Redis 缓存
