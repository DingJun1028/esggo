## Quick Start
### Prerequisites
- Node.js v18+
- PostgreSQL 14+ / Redis 7+
- Gemini API Key
- Google ADK Hardware (Optional for Time Agent)

### Installation & Startup
```bash
# 安裝依賴
npm run install:all

# 啟動開發伺服器
npm run dev

# 啟動 ADK 代理 (需連接硬體)
npm run agent:start
```
