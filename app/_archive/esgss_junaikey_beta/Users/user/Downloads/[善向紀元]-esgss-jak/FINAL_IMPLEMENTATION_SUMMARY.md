## 🚀 **部署與使用指南**

### **快速啟動**
```bash
# 1. 環境準備
npm install
cp .env.example .env

# 2. Supabase 設定
# 執行 supabase-schema.sql
# 設定 Row Level Security

# 3. 初始化萬能元鑰
npm run dev

# 4. 系統就緒
# 訪問 http://localhost:3000
```

### **核心功能使用**
```typescript
// 初始化萬能元鑰
import { omniKeyCore } from './services/omniKey-core';
await omniKeyCore.initialize();

// 智慧 ESG 分析
const insights = await omniKeyCore.navigateIntent({
  userId: 'user-123',
  intent: '分析碳排放趨勢並提供改善建議',
  context: { timeRange: '2024', scope: 'scope1+scope2' }
});

// 系統整合
import { systemIntegration } from './services/system-integration';
await systemIntegration.syncAllSystems();

// 高級分析
import { advancedAnalytics } from './services/advanced-analytics';
const riskAssessment = await advancedAnalytics.performRiskAssessment('company-123');
```
