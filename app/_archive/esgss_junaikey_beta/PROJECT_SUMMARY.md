## 3. Omni Architecture

### 3.1 核心組件 (The Core)
1. **OmniComponentCore (SSOT)**: 奧秘元件心核，所有組件的溯源起點。
2. **OmniAgentService**: 奧秘代理服務，執行 5T 協議的封印與記錄。
3. **OmniReportService**: 奧秘報告服務，生成符合國際標準的 ESG 報告。

### 5T Protocol
| 標籤 | 定義 | 技術實作 |
| :--- | :--- | :--- |
| 🟢 **T1-Tangible** | **可感知** | 將抽象指標轉化為具體 UI。具備「液態玻璃」質感與動態回饋。 |
| 🟢 **T2-Traceable** | **可溯源** | `source_origin` 必須指向原始檔案或 API 來源。每一筆數據必有原始起點。 |
| 🟢 **T3-Trackable** | **可追蹤** | 實作生命週期 Hook。即時紀錄數據在 InfoOne 平台間的流轉路徑。 |
| 🟢 **T4-Transparent** | **可透明** | 算法公式公開化。必須通過「零幻覺驗算」，標註如 [ISO-14064-1]。 |
| 🔴 **T5-Trustworthy** | **不可篡改** | 核心禁區。數據寫入後生成 `SHA-256` Hash，執行 `Object.freeze()`。 |
