# Quickstart Guide

Get up and running with ESGss JunAiKey in minutes.

## 1. Setup Environment

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-repo/esgss-junaikey-beta.git
cd esgss-junaikey-beta
npm install
```

## 2. Configure Credentials

Create a `.env` file based on `.env.example` and add your keys:

- `VITE_SNYK_API_TOKEN`: Your Snyk API token.
- `VITE_SNYK_ORG_ID`: Your Snyk Organization ID.
- `CONTINUE_API_KEY`: Your Continue API key for Agent Mode.

## 3. Authenticate CLIs

Ensure you are logged into Snyk and Continue:

```bash
snyk auth
cn login
```

## 4. Run Your First Continuous AI Scan

Trigger an AI-powered security audit using the Continue CLI:

```bash
cn -p "Run a Snyk Code scan on this repo and propose minimal diffs for the top 3 high-severity issues." --auto
```

## 5. View Documentation

Run the Mintlify development server to preview the docs:

```bash
mintlify dev
```
