這支腳本原本比對「線上 CSS 是否含 .bg-ftg-forest/[0.42]、.bg-ftg-sunlight/[0.56]
等 Tailwind 類名」。2026-10-02 實測 6/6 全數「規則不存在」，兩層原因：

1. 契約方向相反 —— 它斷言「全域遮罩必須存在」，但設計已明確要求
   「照片無全域遮罩、僅文字後一個 rgba(0,0,0,0.5) 方框」。即使類名沒被
   purge，這支腳本也會把修復前的 bug 狀態當成通過條件。

2. 脆弱耦合 —— Tailwind 類名會隨版本升級、safelist 設定與 purge 結果
   改變。以類名比對當驗收，等於把工具產物當契約。

真正的驗收已改寫為瀏覽器量測 computed style，見：
  scripts/verify_live_render.py
它直接量測「全幅半透明層數 == 0」與「文字方框數 == 1」，
不依賴任何 CSS 類名，且對正式域名逐條路由 × desktop/mobile 實測。
