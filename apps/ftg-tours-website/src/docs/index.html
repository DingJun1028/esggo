哲學核心

以終為始，始終如一，無始無終，善向永續

終始矩陣不是點對點的清單，而是生命週期流動的圓環。每一項目都有「起承轉合」四段，前者的「合」即為後者的「起」；循環不息，如山脈綿延、似海浪推湧，沒有真正的起點，亦沒有真正的終點。

🎯

以終為始

從終態圓心反推，但知圓心本身也在漂移

💎

始終如一

無論流轉萬變，初心（使用者體驗）不動

♾️

無始無終

第一「起」來自需求，最後「合」回到需求

🌱

善向永續

每一循環都朝 ESG 正向影響更進一步

六流體系

每一條流都是一條獨立的河，有起點有終點，有深度有節奏。企業可以只取一瓢飲，也可以讓六流匯聚成海。

🌱

覺曉流

Awareness

讓 ESG 從抽象變具體。當員工彎腰撿起第一片垃圾，ESG 不再是報告上的數字，而是「我親手做過的真實故事」。

「員工親身參與永續行動」
🤝

凝聚流

Cohesion

團隊在自然中重建信任。在遠離辦公室的山林裡，主管們脫下頭銜的盔甲，重新看見彼此。

「主管在山林間說出真心話的瞬間」
🌲

復元流

Restoration

身心在高壓後恢復。不是逃避工作，而是學會真正的修復 — 在自然中找回呼吸的節奏。

「第一次在森林中真正放下手機」
👨‍👩‍👧

共好流

Mutuality

企業關懷延伸至家庭。邀請家人一起走進自然，讓「幸福企業」成為孩子記憶裡溫暖的週末。

「孩子第一次和父母在自然中完成任務」
📊

留念流

Memorial

活動成果化為影響素材。將每一次行動轉化為可量化的影響力報告，讓「我來過、我做過」成為可分享的證據。

「看見自己的行動被記錄成數字」
🏔️

基礎流

Foundation

一切的核心體驗載體。沒有體驗的深度，其他流就無法流動。每一次出行，都應該成為值得說出來的故事。

「每一次出遊都成為故事」

🌊 六流功能模組

🌱 覺曉流 — ESG 戶外團隊日

  • Clean-up Walk — 垃圾撿拾數量、重量、類型
  • 碳足跡記錄 — 距離 × 排放係數（步行/腳踏車/捷運/火車/汽車/飛機）
  • 生態觀察 — 物種名稱、數量、棲息環境
  • 地方支持 — 在地消費商家、金額、類型
  • 水資源 — 用水量、用途、節約量
  • 廢棄物減量 — 自備餐具/水壺/購物袋

🤝 凝聚流 — 高階主管共識營

  • Opportunity Map — 痛點、機會、顧客需求、解決方案
  • 3 年策略路徑 — Year 1 基礎 / Year 2 成長 / Year 3 成熟
  • 共識記錄 — 已達成共識、待處理事項

🌲 復元流 — 員工身心平衡

  • 需求診斷問卷 — 壓力、睡眠、活力、工作生活平衡
  • 六大模組 — 自然修復、正念練習、運動負荷、數位排毒
  • 30-day 追蹤 — 日記提醒、進度可視化、週期回顧

👨‍👩‍👧 共好流 — 企業家庭日

  • 親子任務卡 — 自然賓果、拍照挑戰、尋寶遊戲、手作體驗
  • 自然觀察記錄 — 觀察文字、類型（植物/昆蟲/鳥/其他）
  • 照片上傳 — Base64 編碼、5MB 限制、自動生成 URL

📊 留念流 — ESG Impact Note

  • GRI 框架對應 — GRI 303/304/305/306/403/404/413
  • SDGs 對應 — 17 項指標自動配對
  • 數據視覺化 — Canvas 圖表自動生成
  • 成果摘要 — 參與者、碳足跡、物種觀察、地方消費

🎒 行前準備工具

⚠️ 安全檢查清單

  • 裝備檢查 — 登山鞋、雨具、防曬、個人藥品、足夠飲水
  • 健康評估 — 重大疾病、急救包、醫療站、緊急連絡卡
  • 天氣確認 — 天氣預報、備案路線、撤退點位置
  • 安全須知 — 安全簡報、通訊設備、安全官、緊急連絡群組

🎒 打包清單（12 件）

  • 登山鞋、雨具、防曬、個人藥品、飲水、行動糧
  • 背包、手電筒/頭燈、急救包、手機+行動電源
  • 身分證件、現金

📅 行程管理

  • 月曆模式 — 點擊日期查看/新增行程
  • Todo 清單 — 優先級（緊急/高/普通）、到期日
  • 鬧鐘提醒 — 時間、標籤、單次/每日重複、鈴聲

📖 知識庫（行前/中/後三階段）

  • 行前 — ESG 簡介、SDGs、碳足跡知識、LNT 七原則
  • 行中 — 撿垃圾環境效益、生態觀察價值、在地消費乘數效應
  • 行後 — GRI 報導準則、IRIS+ 影響力衡量

📍 旅程現場工具

📍 GPS 簽到

  • Geolocation API — 取得經緯度
  • 簽到計數器 — 簽到率、連續簽到、歷史記錄
  • 勳章自動授勳 — 首次簽到 / 滿 5 次 / 滿 10 次

  • WatchPosition — 持續追蹤行進軌跡
  • 啟動/停止按鈕 — 即時切換
  • 座標顯示 — 緯度/經度即時更新

⏱️ 碼錶計時器

  • 碼錶 — 精確到 0.01 秒、開始/暫停/重置

🎤 錄音機 & 📸 照片上傳

  • MediaRecorder — 麥克風錄製、webm 格式、即時回放

🔦 手電筒 & 📷 QR Code

  • Screen Lock API — 防止螢幕關閉、全螢幕白光
  • QR 產生/掃描 — 文字/URL 轉 QR、相機掃描解碼

🚌 巴士／交通管理

  • 住宿管理 — 飯店、入住/退房、綠色認證
  • 交通紀錄 — 類型、公司、路線、日期、碳排放

👥 團隊與社交

👥 團隊管理
