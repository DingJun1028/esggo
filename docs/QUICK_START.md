# ESGGO 快速入門指南

## 歡迎使用 ESGGO 善向永續

### 系統概覽
- **OmniAgent**: 智能代理系統
- **5T 協議**: 資料完整性保護
- **Vision API**: 圖片分析
- **DataConnect**: 資料庫整合

### 快速開始

1. **註冊/登入**
   - 點擊右上角「登入」
   - 使用 Google 帳號或電子郵件註冊

2. **上傳憑證**
   - 前往 `/dashboard`
   - 點擊「上傳文件」
   - 支援 PDF、圖片格式

3. **查看分析結果**
   - 系統自動提取 ESG 指標
   - 查看 GRI 標準對應
   - 下載報告

### 功能列表

| 功能 | 說明 | 位置 |
|------|------|------|
| 儀表板 | 績效總覽 | /dashboard |
| 分析 | 文件上傳 | /upload |
| 報告 | 生成報告 | /reports |
| 設定 | 帳號設定 | /profile |

### 支援的模型

- **文字模型**: gpt-3.5-turbo (OpenRouter)
- **圖片模型**: llava-phi3 (本地 Ollama)
- **備用**: gemini-pro-vision
