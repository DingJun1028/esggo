# ADR-010: ESG GO v3.4.0 超覺醒去 Google 獨立化與 5T 協議 2.0 架構

## 狀態 (Status)
**Accepted** (已批准並正式生效)  
**日期**: 2026-10-03  
**版本**: v3.4.0 (CAB Hyper-Awakened)

## 決策背景 (Context)
ESG GO 永續治理平台在升級至 v3.4.0 時，為達成更高層級的資安主權、數據防竄改與極致計算效能，面臨以下關鍵轉折點：
1. **去外包與去 Google 化 (100% De-Google Architecture)**：系統須完全轉向本地 PostgreSQL + Prisma ORM 與自研 REST API 計算引擎，免除第三方服務中斷、隱私洩漏與數據跨境風險。
2. **2024 台電碳排係數同步**：電力排放係數由舊版更新至台電 2024 年最新公告之 `0.494 kgCO2e / kWh`，並結合 DEFRA 2024 範疇一燃料係數。
3. **5T 協議 2.0 強固**：所有寫入與計算產物必須自動綁定 `uuid`、`timestamp`、`source_origin: 'JunAiKey_OmniAgent'` 與 SHA-256 Hash Lock 密碼學封印。
4. **全域零錯誤檢驗**：TypeScript 編譯 (`npx tsc --noEmit`) 零錯誤，並且全儲存庫 UTF-8 編碼純淨無亂碼。

## 決策內容 (Decision)

1. **本地 Carbon Emissions REST API 計算引擎**
   - 新增 API 路由 `app/api/calculator/carbon-emissions/route.ts`。
   - 支援 Scope 1 (汽油 2.312、柴油 2.688、天然氣 2.021 kgCO2e/unit)、Scope 2 (電力 0.494 kgCO2e/kWh) 與 Scope 3 (商務差旅 0.115、物流運輸 0.105 kgCO2e/unit) 本地即時試算。
   - 計算結果自動進行 5T 雜湊鎖 (SHA-256) 刻印並回傳標準 5T Protocol 驗證結構。

2. **全域健康診斷工具 `scripts/omni-healthcheck.mjs`**
   - 採用純原生 ESM (.mjs) 寫作，診斷 Node.js 環境、Prisma PostgreSQL 資料庫連線狀態、核心檔案 UTF-8 純淨度、PWA manifest.json 與 5T SHA-256 密碼引擎。
   - 提供「全真綠」的一鍵式自動化診斷回饋。

3. **永續中心 UI/UX 升級 (Liquid Glass Cyan)**
   - 在 `app/sustain-center/page.tsx` 整合 2024 最新台電係數與 GRI/TCFD/CSRD 國際標準矩陣。
   - 完全遵循 Liquid Glass Cyan (`#06b6d4`, `#10b981`, `#020617`) 視覺風格與 W3C ARIA 無障礙標準。

4. **無縫驗證憑證 REST API**
   - 提供 `app/api/verifier/certificate/[id]/route.ts` 公開憑證檢驗介面，支援跨 MaterialityAssessment, NetZeroRoadmap, SupplyChainVendor 等 5T 紀錄的即時防僞查驗。

## 產出與影響 (Consequences)

### 正向影響 (Positive)
* **資料主權與資安等級最大化**：100% De-Google 獨立架構確保完全掌握資料與計算邏輯。
* **精準合規**：符合經濟部能源署及台電 2024 排放係數標準，提供精準碳盤查數據。
* **高可追溯性**：每一筆運算皆附帶 5T Hash Lock 密碼證明與追溯標籤。
* **強固程式碼庫**：TypeScript 零錯誤與全真綠編碼規範確保儲存庫長期可維護性。

### 需注意的後續行動 (Follow-up)
* 定期透由 `node scripts/omni-healthcheck.mjs` 進行系統診斷。
* 若能源署更新 2025 電力排放係數，於 `EMISSION_FACTORS` 集中調整即可。
