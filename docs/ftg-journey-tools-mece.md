## 角色矩陣（RBAC）

| 角色 | 說明 | 權限範圍 |
|---|---|---|
| 👑 **Admin** | 系統管理員 | 全部功能 + 成員管理 + 數據匯出 |
| 🧑‍💼 **Staff** | 工作人員/福委會 | 全部功能（含建立旅程） |
| 👤 **Member** | 一般參與者 | 自身參與的旅程功能 |
| 👀 **Guest** | 訪客 | 僅瀏覽公開資訊 |

## MECE 對照：舊版 vs 新版

| 問題 | 舊版 | 新版（MECE + RBAC） |
|---|---|---|
| 分類混亂 | 行前/行中/行後 + 功能混雜 | 6 大獨立分類 |
| 功能重複 | 照片在多個地方出現 | 統一在 B-行中記錄 |
| 命名不一致 | 代辦/備忘/筆記混用 | 各自獨立定義 |
| 擴展性差 | 新功能不知道放哪 | 對號入座即可 |
| 權限混亂 | 所有人看到一樣 | 角色自動過濾 |
