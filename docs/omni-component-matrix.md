## 📋 矩陣定義

本文件將 `ESGGO OmniComponent Library v1.2.0`
中的所有功能元件，映射至「終始矩陣」，以確保每個元件都屬於一個完整的功能設施體系。

矩陣採用的 **六式循環** 架構 (The Six-Form Loop) 進行標記：

1. **覺式 (Awaken)**: 接收輸入，喚醒任務。
2. **解式 (Deconstruct)**: 拆解意圖，形成結構化任務。
3. **策式 (Strategize)**: 生成策略，構建執行路徑。
4. **貫式 (Execute)**: 跨平台執行，落地任務。
5. **迴式 (Feedback)**: 收集結果，回饋修正，執行 5T 驗證。
6. **鍛式 (Forge)**: 沉澱知識至永憶庫。
