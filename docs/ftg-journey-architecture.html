FTG Journey App — 系統架構圖

六流終始矩陣 × MECE 工具組 × RBAC 角色權限

前端技術棧

  • • React 19 + React Router 7
  • • Vite 8 + Tailwind CSS 3
  • • framer-motion 11（動畫）
  • • react-hook-form 7 + date-fns 4
  • • 純前端 SPA，狀態經 AuthContext 管理

後端技術棧

  • • Node.js 22 + Express 4
  • • node:sqlite（內建 SQLite）
  • • google-auth-library（OAuth 驗證）
  • • express-rate-limit（120 req/min）
  • • JWT + Token Refresh + Role Resolution

部署架構

  • • Docker Compose（backend + nginx）
  • • Oracle VPS（4OCPU/24G ARM）
  • • Cloudflare DNS + orange-cloud proxy
  • • Let's Encrypt SSL/TLS
  • • systemd auto-restart + 5T 驗證

資料庫（17 表）

  • • 核心：users, journeys, members
  • • 內容：prep, schedule, notes, impact
  • • ESG：esg_task_logs, badges, user_badges
  • • 工具：checkins, executive_tools, wellbeing
  • • 人員：suggestions, lost_items, rooms, groups

安全機制

  • • Google OAuth 2.0 + JWT
  • • Token 7 天寬限期自動刷新
  • • Role-based Access Control（RBAC）
  • • Path traversal guard + HMAC 驗證
  • • Rate limiting + CORS + HTTPS only

MECE 工具組

  • • A. 行前準備（倒數/裝備/連絡卡）
  • • B. 行中記錄（筆記/拍照/定位）
  • • C. 人員管理（專案組/房號/分組）
  • • D. 旅行物流（機票/飯店/交通）
  • • E. 永續學習（ESG 知識/勳章）
  • • F. 實用工具（手電筒/碼表/錄音）
