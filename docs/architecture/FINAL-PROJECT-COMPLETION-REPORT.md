## 使用範例

### TypeScript/Node.js

```typescript
// 完全自主代行
import { createDelegation } from './src/core/omni-core';

const agent = await createDelegation({
  principalId: 'user-123',
  permissions: ['full'],
});

// ESG 分析
import { esgAnalysisEngine } from './src/lib/esg-analysis';

const result = await esgAnalysisEngine.analyze(
  environmentalMetrics,
  socialMetrics,
  governanceMetrics,
  { start: new Date('2024-01-01'), end: new Date('2024-12-31') }
);
```

### CLI

```bash
# 完全自主代行
esggo-delegation create --principal user-001 --permissions full
esggo-delegation list
esggo-delegation execute <id> --intent "generate-report"
```

### API

```bash
# 完全自主代行
curl -X POST http://localhost:3000/api/delegation

# ESG 分析
curl -X POST http://localhost:3000/api/esg/analyze
```

### Demo 頁面

```bash
# 完全自主代行
open public/demo/delegation.html

# ESG 分析
open public/demo/esg-analysis.html
```
