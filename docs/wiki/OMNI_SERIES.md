# ESGGO 萬能系列組件 | Omni Series Components

## 定義 | Definitions

### 萬能永憶 [Omni Memory]

**Purpose**: 分散式記憶體儲存系統

- 5T 協議遵循: T1-追溯、T3-型別化
- 記憶片段不可變更，僅追加
- 跨 Agent 共享上下文

### 萬能智庫 [Omni Knowledge Base]

**Purpose**: ESG 知識管理中心

- RAG 引擎整合
- 向量索引自動更新
- 來源可追溯

### 萬能符文 [Omni Runes]

**Purpose**: 可執行的符號定義

- 觸發條件: 事件、狀態、數據
- 執行動作: API 調用、工作流
- 狀態機管理

### 萬能筆記 [Omni Notes]

**Purpose**: 智能筆記系統

- 雲端同步: 多裝置一致性
- 智能標籤: 自動提取
- 反向連結: 內容關聯

### 萬能標籤 [Omni Tags]

**Purpose**: 智能標籤管理

- 自動標籤: AI 識別
- 手動標籤: 用戶編輯
- 層級標籤: 多維分類
