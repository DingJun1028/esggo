# ESGGO 功能設施資料庫資源對應矩陣

## 資料庫資源分類

### 1. Supabase 資料表

| 表格                     | 用途              | 路由                                                                |
| ------------------------ | ----------------- | ------------------------------------------------------------------- |
| `omni_matrix_components` | 矩陣元件註冊      | `/dashboard/matrix`                                                 |
| `omni_evidence`          | 證據文件（Vault） | `/vault`, `/proof-center`, `/integrity`                             |
| `omni_notes`             | 筆記系統          | `/omni-notes`, `/think-tank`                                        |
| `omni_tasks`             | 任務管理          | `/tasks`, `/dashboard/premium`                                      |
| `omni_users`             | 使用者資料        | `/profile`, `/login`, `/super-admin`                                |
| `omni_agents`            | 代理人狀態        | `/agents`, `/omni-factory`                                          |
| `omni_reports`           | ESG 報告          | `/sustain-write`, `/publish`, `/audit-verify`                       |
| `omni_metrics`           | 指標資料          | `/dashboard/metrics/*`, `/environmental`, `/finance`, `/governance` |
| `omni_templates`         | 樣板市集          | `/templates`, `/omni-factory`                                       |
| `omni_knowledge`         | 知識庫            | `/academy`, `/reading-room`, `/think-tank`                          |

### 2. Firebase Firestore 集合

| 集合               | 用途     | 路由                          |
| ------------------ | -------- | ----------------------------- |
| `reports`          | 報告文件 | `/sustain-write`              |
| `vault_evidence`   | 加密證據 | `/vault`                      |
| `signatures`       | 5T 簽章  | `/proof-center`, `/integrity` |
| `scraped_articles` | 攝取文章 | `/intelligence`, `/social`    |

### 3. Firebase DataConnect

| 表            | 用途     | 路由                 |
| ------------- | -------- | -------------------- |
| `AuditRecord` | 審計記錄 | `/audit-log`         |
| `User`        | 使用者   | `/login`, `/profile` |
| `Task`        | 任務     | `/tasks`             |

## 資料庫表格建立指令

```sql
-- Supabase 表格
CREATE TABLE IF NOT EXISTS omni_matrix_components (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  route TEXT UNIQUE,
  registered BOOLEAN DEFAULT false,
  five_t_traceable BOOLEAN DEFAULT false,
  five_t_transparent BOOLEAN DEFAULT false,
  five_t_tangible BOOLEAN DEFAULT false,
  five_t_trustworthy BOOLEAN DEFAULT false,
  five_t_trackable BOOLEAN DEFAULT false,
  deliverables JSONB,
  business_logic TEXT,
  uiux TEXT,
  customer_journey TEXT,
  pain_points_solved TEXT,
  last_updated TIMESTAMP DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS omni_evidence (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID REFERENCES omni_reports(id),
  file_name TEXT NOT NULL,
  file_url TEXT,
  hash_lock TEXT NOT NULL,
  uploaded_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS omni_notes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID,
  content TEXT,
  type TEXT,
  pinned BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW()
);
```
