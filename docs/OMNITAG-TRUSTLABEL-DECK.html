現狀的三大缺口

  • OmniTag 雖有 lifecycle，但無法量化信任強度
  • 各 agent 呼叫缺乏統一閘控，錯誤只能事後追溯
  • 凍結鎖的語義模糊：H4 雙鎖與單鎖混用，造成契約不可預期

缺口一 · 無分數

trustLevel 為純字串，無法做數值閘控

缺口二 · 無閘控

各端點都得自行判斷，無統一門檻

缺口三 · 無契約

enforceFrozenLock 雙介面引發測試漂移

§20.7 信任標別系統

五等級 × 三函數 × 二契約

五等級 × 分數

low / medium / high / critical / authenticated

三個內建函數

esggo.trustScore · esggo.trustGate · esggo.trustLabel

兩個契約

validateTrustLevel · enforceFrozenLock（雙介面）

一個工廠

createTrustTag + updateLifecycle + Object.freeze

五個信任等級

LevelScoreLabel Set典型用途
low0.70hash-lock內部日誌
medium0.85third-party-auditCI 流水線
high ★ 預設閘值0.95full-5t-pass, hash-lock所有生產部署
critical1.00h4-frozen, object-freeze金融、憑證
authenticated0.90hmac, oauthOAuth / HMAC 驗證

透明原則：未知等級一律回傳 0，不留 fallback

05 / 12

三個內建函數

import { esggo } from '@/lib/omni-core/omni-function';

// 1. 查分數
esggo.trustScore('high');         // → 0.95
esggo.trustScore('critical');     // → 1.00
esggo.trustScore('unknown');      // → 0

// 2. 閘控
esggo.trustGate('low');           // → { passed:false, threshold:0.95, ... }
esggo.trustGate('high');          // → { passed:true,  threshold:0.95, ... }

// 3. 加標
esggo.trustLabel(tag, 'critical');
//    → 自動補上 trustLevel + trustScore + hashLock + labels

守衛：所有內建函數以 if (!omniFn.has(...)) 防重複註冊

06 / 12

凍結鎖 · 雙介面

H4 雙鎖（舊契約）

永久不可變的金絲雀

enforceFrozenLock(sealed, true);
// → ContractCheck
// 條件：lifecycle:sealed + security:restricted

§20.7 單鎖（新契約）

流程結束即凍結

enforceFrozenLock(frozen, nextPatch);
// → { blocked, violations }
// 條件：lifecycle:frozen

共存設計：向後相容 + 新業務可選。守衛為 typeof second === 'boolean'

使用場景（精選 5 / 12）

  1. CI/CD 部署門控 — 部署前 esggo.trustGate('high')
  2. Webhook 簽章驗證 — HMAC 通過 → authenticated + frozen
  3. 批次稽核 — auditContractRate(tags) 必須 = 100%
  4. H4 vs §20.7 — 永久憑證選 H4，流程凍結選 §20.7
  5. 錯誤恢復 — enforceFrozenLock 被阻擋時，建新標籤取代舊標籤

完整 12 式：見說明書 §8

  });

TRUST_LEVEL_SCORE = {
  'low': 0.7, 'medium': 0.85,
  'high': 0.95, 'critical': 1.0,
  'authenticated': 0.9
}
def trust_score(lvl):
  return TRUST_LEVEL_SCORE.get(lvl, 0.0)
