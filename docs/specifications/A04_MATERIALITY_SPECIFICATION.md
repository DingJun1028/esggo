## 1. 設施願景與定位 (Mission & Vision)

A04「雙重重大性策略評估矩陣」是企業符合歐盟 CSRD（企業永續發展報告指令）與 GRI 通用準則的戰略羅盤。
本設施徹底擺脫靜態 Excel 評估表的低效與黑箱作業，將**「衝擊重大性 (Impact Materiality - 內向外)」**與**「財務重大性 (Financial Materiality - 外向內)」**轉化為即時交互之動態散佈圖，並透過 5T 密碼學封印鎖定重大議題清單，確保企業利害關係人鑑別與策略佈局的絕對公信力。

```
  │  ▸ 分類為 ESG 三大支柱 (環境 E、社會 S、治理 G)

```

## 3. 核心功能規格細節 (Core Functional Specifications)

### 3.1 評估設定控制列 (Assessment Control Bar)
- **年度設定**：支援多年度滾動評估（2025、2026、2027）。
- **準則框架選擇**：`GRI_CSRD`、`ISSB_TCFD`、`SASB_SECTOR`。
- **重大性門檻滑桿 (Threshold Slider)**：
  - 支援 1.0 至 5.0 之浮點數平滑調節（預設 3.5）。
  - 調整門檻值時，矩陣散佈圖背景閥值虛線與「落入重大主題清單」即時連動變更。

### 3.2 2D 雙重重大性散佈矩陣圖 (2D Scatter Matrix)
- **X 軸 (衝擊重大性)**：企業活動對環境與社會之正面/負面影響程度 (1.0 ~ 5.0)。
- **Y 軸 (財務重大性)**：ESG 議題對企業財務現金流、融資成本與獲利之風險與機會程度 (1.0 ~ 5.0)。
- **四象限分區識別**：
  - **右上象限 (雙重重大核心議題)**：財務重大性 ≥ 閥值 且 衝擊重大性 ≥ 閥值。以冷青/翡翠亮色光芒突出。
  - **左上象限 (財務主導議題)**：財務衝擊顯著。
  - **右下象限 (社會環境衝擊議題)**：外部影響顯著。
  - **左下象限 (定期監測議題)**：低度影響，維持例行監控。
- **點擊聯動編輯**：點擊圖表任意主題節點，右側立即展開詳細評估與論證輸入抽屜。

### 3.3 議題編輯工作台 (Topic Configuration Workbench)
- 內建標準 12 項核心議題（氣候變遷與減碳、水資源與循環經濟、生物多樣性、職業安全衛生、人權與勞動實踐、多元共融、供應鏈盡職調查、商業道德與反貪腐、數據隱私與資安等）。
- 支援新增自訂企業特定議題。
- 支援為每個議題紀錄「評分理由與實證依據 (Rationale)」。

### 3.4 5T 密碼學封印與報告導出 (Seal & Export)
- 點擊「封印並儲存評估」：調用 `/api/materiality/assess`，在資料庫建立不可篡改版本。
- 回傳專屬 Hash Lock，呈現封印標籤與時間戳記。
