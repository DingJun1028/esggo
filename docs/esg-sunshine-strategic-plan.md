## 二、核心技術實作：5T 4可1不可 檢驗標準

所有活動參與數據與學員提交的實作原型，必須通過「萬能元件心核」的邏輯門，確保中英一致：

### 5T 協定實作標註樣式

| 英文標準 (5T) | 中文標準 (4+1) | 技術實作檢驗項目 |
|---|---|---|
| Traceable | 可溯源 | 鏈式日誌必須包含 source_origin 與原始資料留存。 |
| Trackable | 可追蹤 | 啟動生命週期 Hook，即時記錄數據流轉路徑。 |
| Transparent | 可透明驗算 | 算法公式公開化（如 ISO-14064-1），通過零幻覺驗證。 |
| Tangible | 可感知 | 將願景轉化為具體的指標成果與實作項目。 |
| Trustworthy | 不可篡改 | Hash Lock 鎖定，寫入後即刻 Object.freeze()。 |

> **規範提醒**：嚴禁使用 "Immutable" 一詞，統一由 Trustworthy (不可篡改) 代替。

## 三、活動實作流程：影響力原型 (Impact Prototype)

我們將在 All in One 平台引導學員進行以下實踐，落實「善向永續願景」：

1. **感知轉化 (Tangible)**：將抽象願景定義為一個可被感知的具體永續指標。
2. **溯源標註 (Traceable)**：標註該指標的原始數據來源（如：工廠電費單據）。
3. **流轉記錄 (Trackable)**：由系統分配 UUID，全程追蹤數據處理進度。
4. **透明運算 (Transparent)**：選擇模型進行驗算，系統自動顯示透明算式。
5. **安全鎖定 (Trustworthy)**：完成實作報告，生成校驗碼並執行雜湊鎖定。
