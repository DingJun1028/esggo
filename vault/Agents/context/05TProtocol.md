# 5T 協定（五大真理原則）

OA-Team 30 萬能蜂群的靈魂核心公約。所有產物必過 5T 驗證閘才能釋出。

## 五原則
- **Traceable 可溯源**：每筆產出標 `source_origin`
- **Trackable 可追蹤**：生命週期 Hook 記錄流轉
- **Tangible 可感知**：UI/UX 質感回饋
- **Transparent 可透明**：零幻覺驗算，演算公開
- **Trustworthy 不可篡改**：Hash Lock + Object.freeze()

## 對映第二大腦
- vault 筆記 frontmatter `source_origin` = Traceable
- [[TypeMatrix]] 的 canonical 單一真相源 = Trustworthy
- [[SyncVaultTypes]] 輸出 JSON.from = Trackable
