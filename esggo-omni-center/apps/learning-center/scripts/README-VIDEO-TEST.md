# AI永續議題影片創作驗證指南

## 概述

本測試套件用於驗證AI影片創作流程是否符合壽司博士品牌標準。目標是在不稀釋原創判斷、不誤導事實、也不犧牲人處境的前提下，將複雜的永續議題蒸餾成觀眻願意看、看得懂、能帶走方法的內容。

## 使用方法

### 1. 執行測試

```bash
cd /c/Project/esggo-learning-center
node scripts/video-creation-test-suite.mjs scripts/test-video-example.json
```

### 2. 輸出檔案

- 測試報告：`test-reports/evaluation-report.json`
- 每次執行會覆寫舊報告

## 七道驗證門檻

### Gate 01: 腳本匯入場景生成
**檢查項目**：
- 場景數量（6-16場/分鐘）
- 時間碼無重疊或斷紀
- 場景內容與腳本一致

### Gate 02: 數據圖卡準確性
**檢查項目**：
- 數字與來源資料庫一致
- 年份在合理範圍內（1900-2030）
- 比較方向視覺化清晰
- 來源標籤可點擊查看

### Gate 03: 視覺一致性
**檢查項目**：
- 所有門檻圖卡使用相同配色
- 字體、字型、間距一致
- 圖標風格統一
- 版面布局一致

### Gate 04: AI B-roll人本感
**檢查項目**：
- 人物表情自然、姿態真實
- 種族、年齡、職業背景多元
- 無機器感或不自然光線
- 情感基調溫和、尊重
- 無恐懼或悲情化刻板印象

### Gate 05: 品牌真實感
**檢查項目**：
- 真實人聲比例 ≥ 30%
- B-roll音效比例 ≥ 50%
- 語言風格符合壽司博士風格

### Gate 06: 子影片切割
**檢查項目**：
- 子影片數量為4支
- 保留原始敘事邏輯
- 門檻圖卡為單一圖片

### Gate 07: 最終定錨驗證
**檢查指標**：
- 觀眻完成率 ≥ 70%
- 事實錯誤率 ≤ 1%
- 人本感評分 ≥ 4/5
- 視覺一致性 ≥ 90%

## 測試資料格式

測試資料檔案需包含以下欄位：

```json
{
  "title": "影片標題",
  "metadata": {
    "style": "professor",
    "brand": "壽司博士",
    "duration": 180,
    "language": "zh-TW"
  },
  "scenes": [...],
  "dataCards": [...],
  "thresholds": [...],
  "broll": {...},
  "audio": {...},
  "subVideos": [...],
  "thresholdCard": {...},
  "metrics": {...}
}
```

## 成功標準

- 所有7道門檻通過
- 總平均得分 100/100
- Exit Code 為 0

## 失敗處理

若測試失敗：
1. 查看報告中`issues`欄位的具體問題
2. 依照問題修正相應的影片元素
3. 重新執行測試
